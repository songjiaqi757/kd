# MOSI 单 seed 实验

服务器共享实验目录：`/ai/sjq/kd/outputs/experiments/mosi_first_20261111_v1`。

按用户最新要求，仅执行学生 seed **13**。不运行 seed 42、2026，也不启动 MOSEI 或其他数据集的新实验。

## 固定训练协议

- 教师：固定 Probe seeds 2026、2027、2028 的已缓存预测。学生 seed 与教师 seed 不同。
- 已将三教师七子集回归均值、校准温度与 KD 温度处理后的分类概率重新计算，与缓存核验一致。
- 学生：Qwen3-0.6B + WavLM-Base-Plus + VideoMAE-Base，三模态 LoRA。
- 每组最多 30 epochs；按 validation MAE early stopping，patience 7。
- batch size 8，learning rate 1e-4，weight decay 0.01，constant learning rate。
- 每组只保留 `best_valid_mae.pt`、`best_valid_acc2_nonzero.pt`、`last.pt`。
- 三份固定检查点分别执行 official-test，输出预测和指标。测试不参与方法、超参数或检查点选择。
- 归一化统计仅从训练集唯一 utterance 估计，标准差 ddof=1，floor 0.05。
- MSE 对照采用 `0.5 * mean((A @ error)^2)`；Smooth-L1 使用 beta=1。

## 调度与查看

Q（36222）、Qiii（34989）、Qiii-A100（31764）各配置两个 worker。每次领取任务同时检查 GPU 现有进程数、剩余显存与共享队列锁；每卡最多两路，空槽立即接后续任务，训练完成后优先执行测试。保留服务器上原有任务。

主要文件：

- `plan.json`：冻结的 18 组配置。
- `queue.json` / `campaign_status.json`：18 个训练、54 个测试任务的实时状态。
- `workers/*.json`：各卡工作进程、子进程 PID 和槽位状态。
- `logs/*.log`：训练和测试日志。
- `runs/*/status.json`：实时 epoch、step 和 loss。
- `summary.md` / `summary.json`：已经完成的测试结果汇总。
- `analysis/mosi_offline_geometry_report.md` / `geometry.json`：矩阵、尺度、协方差、相关性与 Probe 方差。
- `teacher_manifest.json`：教师来源与缺失权重记录。
- `preflight/asset_audit.json`、`objective_checks.json`、`smoke_audit.json`：资产、损失梯度、真实训练及评估检查。

三个原始 Probe 权重缺失，已跳过需要重新加载这些权重的操作；现存预测缓存经过核验，可用于学生训练。历史 F7/E4 权重也没有在原目录发现，因此不从这些历史权重做诊断或续训。新 F7/E4 对照从齐全的学生预训练编码器初始化。

本轮是单 seed 探索，不进行跨 seed 统计或方法稳定性确认。没有自动生成自适应残差方法。

## 训练预算修订

用户要求由 40 epochs / patience 8 改为 30 epochs / patience 7。正在训练的任务在完整 epoch 检查点处暂停，再恢复模型、优化器、随机数和早停计数。原协议和源文件哈希保存在 `maintenance/30epochs_patience7/`；每个恢复任务保留 `run_config.original_40epochs_patience8.json` 和 `protocol_amendment.json`，不重写已有训练历史。
