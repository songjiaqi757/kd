## 论文给出的边界

### DGL，ICCV 2025

[Boosting Multimodal Learning via Disentangled Gradient Learning](https://arxiv.org/html/2507.10213v1)。重点见§3.2、§4.3。单模态损失更新编码器，多模态损失更新融合模块和分类器，通过截断梯度分离优化。它提示应检查不同模块接受的训练信号，而不只是调整全局损失系数。论文包含三模态 MOSI 分类实验，但不能据此推断当前回归模型的 MAE 会改善；其理论设置也不等同于本项目的 Transformer、LoRA 和 Huber 损失。

### LSMI，ICML 2025

[Efficient Quantification of Multimodal Interaction at Sample Level](https://proceedings.mlr.press/v267/yang25aj.html)，[全文](https://arxiv.org/html/2506.17248v1)。§4.3.2 已用样本级冗余、独有、协同信息指导蒸馏：前两者用于单模态特征，协同用于输出蒸馏，并按交互量加权。因此，“估计交互后选择蒸馏内容或加权”已经有直接先例，不能作为本项目的新颖性主张。

### DMIL，CVPR 2026

[Information-Theoretic Decomposition for Multimodal Interaction Learning](https://arxiv.org/html/2606.11614v1)。该方法分解交互表征，并通过分阶段学习、门控聚合利用样本差异。主表的 MOSEI 是视觉+文本二分类；§4.4 另有三模态扩展，不能误写成只支持双模态。它未提供与本项目相同协议的情感强度 MAE 对照。普通“共享/私有/协同分支+门控”已有明显先例。

ICD 的 Möbius 高阶项不等同于 PID 的协同信息。例如空集为0，两个单模态和联合预测均为1，则二阶项为-1；这不能直接解释为有害协同。后续命名和论证应保留这个区别。

## 优先方向：按交互阶数分配梯度更新模块

研究问题：高阶坐标由多个预测相减构成，其监督是否适合直接更新所有单模态编码器？当前证据只能提出这个问题，尚未证明答案。

令 L0 为原监督任务和 FullKD，L1 为一阶 ICD，L23 为二、三阶 ICD。保持原来的逐坐标缩放，使 L1+L23 与原 ICD 一致。第一版只做一个变化：

```
编码器和单模态池化模块：grad(L0 + lambda * L1)
融合模块与预测头：      grad(L0 + lambda * (L1 + L23))
```

这样原任务和 FullKD 仍训练整网；只有高阶交互蒸馏停止更新编码器。无需增加推理参数，但可能增加训练反向传播成本，需要实测。不要直接照搬 DGL，把所有多模态任务梯度都截断。

与现有方法的区别：PCGrad 调整梯度方向；坐标兼容性调整损失权重；这里控制某类监督更新哪组参数。其潜在贡献是“交互阶数与参数更新位置的匹配”，而非梯度截断本身。

必须有原始 ICD、DGL 适配、按阶数分配，以及不依赖阶数的匹配控制。控制组应尽可能匹配被阻断坐标数量和梯度范数，避免收益仅来自减弱辅助损失。现有 shared dropout 也应作为独立因素固定，不能同时改动后归因给新方法。

失败条件：如果高阶蒸馏在编码器上的梯度没有明显不稳定或冲突，或截断后损失了必要的跨模态共同适应，这条路线应降级。不能先承诺它一定提高 MAE 和 Acc2。

## 第二方向：修正教师交互目标，而不仅调整权重

[Knowledge Distillation as Semiparametric Inference，ICLR 2021](https://arxiv.org/abs/2104.09732) 已研究教师过拟合、欠拟合，并提出交叉拟合和损失修正。因此，教师纠错本身并不新。这里的候选问题是：能否在维护七子集重构一致性的同时修正错误教师目标？以下公式是本项目待验证的构想，不是该论文的方法。

教师平均坐标为 mu，空集基线为 b，训练标签为 y。拟议目标为：

```
mu_star = mu + Sigma @ 1 / (1.T @ Sigma @ 1 + sigma_y^2)
                * (y - b - 1.T @ mu)
```

这是一个带标签噪声的线性高斯校正设想：按不确定性分配整体预测残差，而非把所有坐标同幅度拉向标签。Sigma 需要可检验的误差模型；三个探针的分歧只是稳定性线索，不等于真实教师误差协方差。单样本三探针协方差秩最多2，不能直接当成可靠的七维估计；需训练集共享估计、收缩或简单对角版本。

先按 source video 划分训练折，在缓存教师特征上重训轻量探针，生成折外预测，检查教师训练内/折外误差。无需为此重跑30B教师。标签和所有校正统计仅用训练部分，验证用于固定协议选模，测试不能参与校正。

FullKD 与 ICD 应使用一致的教师来源，否则校正后的交互目标可能与原单探针 FullKD 冲突。必须比较：仅统一教师来源、仅交叉拟合、普通标签混合、七子集校正、结构化交互校正。若结构化版本不能优于简单标签混合，就不能主张交互结构带来额外价值。这一方向成本和不确定性高于梯度分配，适合作为第二优先级。

## 推荐实验顺序

1. 先用已有 checkpoint 与固定训练小批次诊断，不重复完整训练。按文本/音频/视频编码器、池化、融合、预测头分别记录 L0、L1、L23 的梯度范数、余弦和非有限值；固定并记录随机状态。仅凭已有 fusion 诊断不能推断编码器冲突。
2. 检查末期退化是否与预测分布饱和、梯度异常、少数批次或某个模块相关。对比最佳与 last checkpoint，不能拿两个方法各自末轮当正式优劣结论。
3. 有证据后优先做按阶数分配的最小实验。正式比较统一 seeds13、42、2026。先核对数据、资产、优化器、步数、随机设置和代码版本，满足协议的已有 baseline 直接复用；不为凑表格无理由重训。
4. 两种选模分别完整报告 MAE/Acc2/Corr/F1，不把 MAE-best 和 Acc2-best 的最优数值拼成一个模型；只保留两种最佳和 last。验证筛选完成后锁定方法，再作官方测试确认。

新颖性结论：当前最值得检验的是交互阶数与优化模块的关系；其次是结构一致的教师纠错。两者都是待验证研究假设，有限文献检索不能证明此前无人提出相似方法。
