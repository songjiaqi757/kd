## 0. 摘要

本项目研究的问题是：在固定学生架构、输入和可训练适配范围的前提下，把 30B 教师模型的监督从“只匹配完整 TAV 输出”改为“匹配教师的多模态交互坐标”，能否带来更稳定、更可解释的情感预测收益。

截至本报告快照，项目已形成以下主结论。

1. **ICD 的主要稳定收益在机制层，而不是在所有数据集的任务指标上全面领先。** 在 MOSEI 三种子上，ICD 的平均 official-test MAE 为 `0.4762 ± 0.0045`，低于 Full KD 的 `0.4798 ± 0.0019`，Pearson/Acc-2/F1 均值也更高；但逐 seed 看 MAE 仅 2/3 改善，差值远小于 seed 间标准差，不能称为显著。MOSI 三种子上 ICD 的平均 MAE 反而比 Full KD 高 `0.0072`（2/3 seed 退化），但 Acc-2 三项 seed 全部改善约 `0.86` 个百分点。ICD 不是 MOSI 上的任务指标全面最优方法。
2. **交互重建是 ICD 最一致的优势。** 七坐标重建 MAE 从 Full KD 的 MOSEI `0.4486` / MOSI `1.1438` 降到 ICD 的 `0.2669` / `0.5384`。MOSEI 上 First+Second-order 的七坐标均值略低于 ICD（`0.2653` vs `0.2669`），MOSI 上 ICD 最低；因此不能声称 ICD 在每一阶都最好，但“恢复教师交互结构”这一层证据很强。
3. **跨模态保真度与 polarity 纠正存在关联，但不是因果。** 被 ICD 纠正 polarity 的样本相较被 ICD 改错的样本，cross-modal fidelity gain 更大：MOSEI `+0.0677`（原视频聚类 95% CI `[+0.0096,+0.1256]`），MOSI `+0.4187`（CI `[+0.2201,+0.7353]`）。MOSI 的 corrected/harmed 各只有 9 条、6 个源视频 cluster，只能作为小样本探索性证据。总体 Acc-2 的 McNemar 检验不显著（MOSEI `p=0.5507`，MOSI `p=1.0000`）。
4. **部署成本几乎不变。** ICD 与 Full KD 均为 `819.309M` 部署参数、`42.650M` 可训参数；batch-1 峰值 allocated 显存 `2.091 GiB`；model-only p50 约 `95 ms`；端到端吞吐 `1.630 utt/s`，与 Full KD 相同。相对 30B 教师，学生参数压缩 `38.72×`，batch-1 峰值显存压缩 `32.29×`，端到端吞吐约 `2.22×`。
5. **方法扩展的负结果同样重要。** MOSEI 的六种 equal-modality 变体中，没有任何一种在三种子上稳定优于原 ICD（最好的 `explicit_uniform_interaction` 平均 MAE 仅低 `0.00055`，2/3 seed 改善，差值远小于方差）。MOSI 的 14 方法三 seed 研究中，梯度投影（`0.7332→0.7089`）和坐标兼容加权（`0.7257`）通过了预设验证筛选，但尚无跨数据集确认。按阶数路由、共享 dropout、DGL 适配、后期衰减、显式架构等均未达到预设综合门槛。
6. **跨数据集 SIMS/SIMS v2 为 ICD 提供了最强支持。** SIMS 主表 ICD 测试 MAE `0.3866`（六方法最低），SIMS v2 `0.3396`（最低）；三种子消融均值也均为最低（`0.3947` / `0.3398`）。但主表只有 seed13，消融的 Acc-2/Acc-5 并非每项都由 ICD 最好。
7. **教师侧仍有明显 headroom，尤其在 MOSI。** 30B + Probe 的 official-test MAE 为 MOSEI `0.4429`、MOSI `0.4802`；对应学生 ICD 为 `0.4762` / `0.7388`。MOSEI 差距约 `0.033`，MOSI 差距约 `0.259`，说明 MOSI 的瓶颈更可能来自学生容量/适配与目标可学性，而不是教师标签本身。

## 1. 研究目标与项目沿革

### 1.1 核心命题

项目检验的不是“大模型教师是否比小模型强”，而是：

> 在相同学生编码器、相同 TAV 输入、相同 LoRA 适配范围和相同评测协议下，**选择性地迁移教师的交互知识**，能否比普通输出蒸馏（Full KD）、直接匹配七个子集输出（Subset-7）、或仅迁移一阶/一二阶交互，带来更好的任务表现和更可解释的机制证据。

这一问题被拆成三层对照：

| 层 | 对照 | 回答的问题 |
|---|---|---|
| 监督量 | Adapted Student vs Full KD vs Subset-7 | 收益是否只是“多给了教师监督”？ |
| 监督组织 | Subset-7 vs First-order vs First+Second-order vs Uniform ICD vs Random Orthogonal | 收益是否来自交互坐标这一特定基，而不是任意七维线性变换？ |
| 选择性加权 | Uniform ICD vs R-only / U-only / R×U | Probe 稳定性 R 与任务关联 U 是否必要？ |

## 2. 方法与系统

### 2.1 教师侧：Qwen3-Omni + 七子集 Probe

- 教师模型：`Qwen3-Omni-30B-A3B-Instruct`，15 个权重分片，BF16，双卡 model-parallel 前向。
- 输入：完整 TAV 以及七个非空模态子集 `T / A / V / TA / TV / AV / TAV`。
- 特征：取最后一个有效输入 token 的 Thinker hidden state，维度 `2048`，FP16 缓存。
- Probe：`LayerNorm(2048) → Linear(2048,512) → GELU → Dropout(0.1)`，接七分类头与标量回归头 `3·tanh(Linear(512,1))`。
- Probe 种子：`2026 / 2027 / 2028`；ADAMW，lr `1e-3`，weight decay `1e-4`，batch `128`；损失为 weighted Smooth-L1 + `0.5 ×` 七分类 CE；最多 200 epoch，patience 25。
- 选模：official validation 的 joint loss 最小；seed2026 固定用于单 Probe TAV 目标，三个 Probe 的均值/方差用于交互目标与 ensemble 目标。
- 温度校准：validation NLL 上拟合标量温度。MOSEI 三个 Probe 为 `1.0115 / 1.0668 / 1.0081`；MOSI 为 `1.1912 / 1.2059 / 1.1803`。
- 关键边界：三个 Probe 不是三个独立的大模型教师；它们共享同一教师的特征缓存。

### 2.2 学生侧：0.82B TAV 学生

| 模态 | 编码器 | 适配 |
|---|---|---|
| Text | `Qwen3-0.6B-Base` | T/A LoRA，rank 8 |
| Audio | `WavLM-Base-Plus` | T/A LoRA，rank 8 |
| Video | `VideoMAE-Base`（Kinetics-400 自监督） | 视频末端 12 层 LoRA，rank 8，alpha 16，dropout 0.05 |

- 融合：每个样本只做一次 T/A/V 编码，七种模态子集复用同一组编码表示，通过模态屏蔽构造七个子集的前向。
- 推理：只使用完整 TAV，不集成七个子集预测，也不加载教师。
- 参数量：部署 `819.309M`；可训 `42.650M`（T/A/V LoRA + 池化/融合/预测头）。
- 训练：AdamW，lr `1e-4`，weight decay `0.01`，batch size `8`；主实验 20 epoch 固定预算（P0 早期协议为最多 30 epoch、patience 7、min_epochs 8）；SIMS 为 `min_epochs=20, patience=20`，不早停。
- 损失：`L_task + L_reg + L_KL`，其中 `L_task` 含回归 + `0.5 ×` 七分类 CE；`kd_temperature=2.0`。

### 2.3 交互坐标与 ICD 损失

对任意子集 `S`，教师 Probe 给出预测 `f_t(S)`；学生给出 `f_s(S)`。基线 `b` 取每个 Probe 在 official train 上完整 TAV 的平均预测，学生使用三个教师基线的均值。Anchored Möbius 分解为：

```text
I(T)   = f(T) - b
I(A)   = f(A) - b
I(V)   = f(V) - b
I(TA)  = f(TA) - f(T) - f(A) + b
I(TV)  = f(TV) - f(T) - f(V) + b
I(AV)  = f(AV) - f(A) - f(V) + b
I(TAV) = f(TAV) - f(TA) - f(TV) - f(AV) + f(T) + f(A) + f(V) - b
```

七个原始子集分数与七个交互坐标在给定 `b` 下可互相转换；变换本身不增加教师信息，改变的是**监督的组织方式**。

公共损失：

```text
L_base = L_task + λ_full · L_reg(TAV) + λ_full · L_KL(TAV)
L_ICD  = L_base + λ_interaction · mean_k w_k · SmoothL1(I_s,k, I_t,k)
```

- `λ_full = 1.0`，`λ_interaction = 1.0`，`alpha_ce = 0.5`。
- Uniform ICD：`w_k = 1/7`。
- R×U：`R_k = |mean(I_k)| / sqrt(var(I_k)+1e-4)`，`U_k = max(|Pearson(I_k, y_train)|,0.01)` 后均值归一化，`w_k ∝ R_k·U_k`，再做逐样本均值归一化与 `[0.25,4.0]` 截断。
- 关键解释边界：`U` 是训练标签关联代理，不是因果 utility；`R` 同时包含交互幅度与 Probe 间稳定性，不是纯不确定性；`R×U` 不是最终 ICD，`M4 = Uniform Interaction` 才是最终方法。

### 2.4 方法族

| 方法 | 额外目标 | 说明 |
|---|---|---|
| Adapted Student | 无 | 与 M3/M4/M6 相同 T/A/V LoRA 适配范围，只训练任务损失 |
| Full KD | 完整 TAV 回归 + 分类 | 单 Probe（seed2026） |
| Ensemble Full KD | 完整 TAV 回归 + 分类 | 三个 Probe 校准概率/分数的均值 |
| Subset-7 KD | 七个子集原始预测 | 均匀权重，直接匹配 |
| First-order Interaction | 仅 `T/A/V` 三个一阶坐标 | 均匀权重 |
| First+Second-order | 一阶 + 二阶（`TA/TV/AV`） | 不含三阶 |
| Uniform Interaction (ICD) | 七个交互坐标 | 均匀权重 |
| Random Orthogonal | 七个随机正交坐标 | 固定坐标随机种子 `20260922`，不随训练 seed 变化 |
| Projector Feature KD | 学生融合表示投影到教师 2048 维 | AAAI 2024 适配 |
| EA-KD | 熵加权分类蒸馏 | ICCV 2025 适配，`log(7)` 上界 |
| CMAD-style CAFD | 逐样本特征 MSE + 跨样本相关 + 双向 KL | ICCV 2025，仅 CAFD，不含 MAR |

## 3. 数据与实验协议

### 3.1 数据集

| 数据集 | Train | Valid | Test | 标签范围 | 备注 |
|---|---:|---:|---:|---|---|
| CMU-MOSEI | 16,326 | 1,871 | 4,659 | `[-3,3]` | 22,856 utterances；train+valid 窗口 18,278 |
| CMU-MOSI | 1,284 | 229 | 686 | `[-3,3]` | 2,199 utterances；test 非零标签 656 |
| SIMS | 1,368 | 456 | 457 | `[-1,1]` | 官方 CSV 划分，原生标度 |
| SIMS v2 有标注集 | 2,722 | 647 | 1,034 | `[-1,1]` | 完整 `meta.csv` 4,403 条中仅有标注 clip；保留官方划分 |

- MOSEI/MOSI 使用官方 split，不重新划分；`official_test_windowed.jsonl` 为长样本窗口化后的测试清单。
- 超过 30 秒的样本按最长 30 秒、重叠 5 秒切窗，并用重叠校正权重聚合到 utterance。
- 500 条教师基准来自 500 个不同源视频，train/valid 为 450/50；测试集不参与教师基准。
- SIMS v2 记录了原视频在 split 间的重叠，但不重新划分；这是跨数据集结论的一个限制。

### 3.2 评测指标

| 指标 | 定义 |
|---|---|
| MAE | 连续情感分数平均绝对误差；MOSEI/MOSI 为 `[-3,3]`，SIMS 为 `[-1,1]`，不可跨标度直接比较 |
| Pearson | 预测与真实分数的 Pearson 相关 |
| Acc-2 NZ / F1 NZ | 排除真实标签为 0 的 Acc-2 / weighted F1 |
| Acc-2 HZ / F1 HZ | 保留真实标签为 0 的 Acc-2 / weighted F1 |
| Acc-7 | 七分类准确率（MOSEI/MOSI） |
| Acc-3 / Acc-5 | SIMS 的三档/五档准确率；SIMS 官方 Acc-2 将 `<=0` 作为非正类 |
| 交互重建 MAE | 七坐标 `(3×First + 3×Second + Third)/7`，统一后验到同一 Anchored Möbius 坐标系 |

`±` 一律为 seed 的样本标准差（sample SD），不是置信区间，也不是三个模型预测的 ensemble。

### 3.3 Checkpoint 选模与测试口径

项目在 2026-10 后统一采用**双 checkpoint**口径：

- `best_valid_mae.pt`：official validation MAE 最小；并列取最早 epoch。
- `best_valid_acc2_nonzero.pt`：official validation Acc-2 NZ 最大；并列取最早 epoch。
- `best.pt` 指向 MAE 最优；`last.pt` 只用于续训。
- 每个 checkpoint 只在其对应策略下评测一次 official test；同一行的所有指标必须来自同一 checkpoint，禁止拼接不同 epoch 的最优值。

本报告的主表使用 `valid_mae` 策略；`valid_acc2_nonzero` 作为完整次级报告，不事后替换主策略。历史 `test-best` sweep 只作诊断，不进入正式主表；且历史 sweep 已经看过 test 的事实不会因重新选模而消失。

解读：

1. **ICD 的 MAE 均值最低，但与 Random Orthogonal 的差距只有 `0.0005`**，远小于两者 seed SD（`0.0045` / `0.0031`）。不能据此声称“语义交互基显著优于随机正交基”。Random 的价值在于提供了一个强对照：任意固定正交基也能获得相近的任务 MAE，因此 ICD 的独特性必须由交互重建证据而非单一任务 MAE 支撑。
2. **Subset-7 与 First+Second 的 MAE 与 ICD 基本同档**（`0.4780` vs `0.4762`）。这说明“多子集监督”本身贡献很大；把七个原始预测换成七个交互坐标，带来的任务增益很小。
3. **First-order 单独使用并不差**（`0.4814`），但也没有超过 Full KD。跨模态高阶项不是任务 MAE 的必要条件。
4. **ICD 的 Pearson 均值最高**（`0.8237`），且在 3/3 seed 上相对 Full KD 改善 Pearson（见 5.1 配对表）。这支持“交互坐标改善了连续排序结构”，但不足以支持“所有任务指标全面最优”。
5. **Ensemble 只有 1 seed，且 MAE 最差**（`0.4869`）。这削弱了“简单三 Probe 集成就能解释 ICD 收益”的替代解释，但还不能替代完整的 ICD-single 2×2 因子实验。

## 7. 跨数据集：SIMS / SIMS v2

### 7.1 协议

SIMS 与 SIMS v2 使用各自官方 CSV 划分、教师资产与训练输出，独立于 MOSI/MOSEI：

- 标签直接使用原始 `[-1,1]`，不做比例映射；MAE 在原生标度上计算，不能与 MOSEI/MOSI 的 `[-3,3]` MAE 直接比较。
- 学生回归输出为 `tanh`，范围 `[-1,1]`；分类头改为五档：`[-1,-0.7]`、`(-0.7,-0.1]`、`(-0.1,0.1]`、`(0.1,0.7]`、`(0.7,1]`。
- 主表 6 方法（Adapted / Full KD / Projector / EA-KD / CMAD / ICD）只跑 seed13；消融表 6 方法（Full / Subset-7 / First / First+Second / Random / ICD）跑 3 seeds。
- Full KD 与 ICD 的 seed13 在两张表间复用；每个数据集 22 次训练，共 44 次。
- 学生固定 20 epoch，`min_epochs=20, patience=20`，不早停；batch 8，lr `1e-4`，weight decay `0.01`。
- 同时保留 `best_valid_mae.pt` 与 `best_valid_acc2.pt`，分别评测一次 official test；主表按 MAE-best。
- SIMS 官方 Acc-2 将 `<=0` 作为非正类，包含零标签；这与 MOSI/MOSEI 的 NZ 口径不同。

### 9.3 Cross-modal fidelity 与 polarity outcome

定义 `E_cross=(e_TA+e_TV+e_AV+e_TAV)/4`，`ΔE_cross=E_cross,Full−E_cross,Uniform`；正值表示 ICD 恢复了更多教师跨模态交互结构。

**连续误差诊断**

| 数据集 | Mean ΔE_cross | Mean ΔM | Spearman ρ | Video-cluster 95% CI |
|---|---:|---:|---:|---:|
| MOSEI | +0.211872 | -0.003293 | +0.0118 | [-0.0333, +0.0589] |
| MOSI | +0.736032 | -0.031203 | +0.0271 | [-0.0916, +0.1379] |

连续 fidelity gain 与任务误差改善**没有显著单调关系**（两个 CI 都跨 0）。

**Polarity outcome 分组（组内 mean ΔE_cross）**

| 数据集 | Outcome | N / video clusters | Mean ΔE_cross | Cluster-bootstrap 95% CI |
|---|---|---:|---:|---:|
| MOSEI | Full wrong → ICD correct | 54 / 44 | +0.128126 | [+0.090106, +0.171520] |
| MOSEI | Both correct | 1,208 / 273 | +0.248418 | [+0.231158, +0.266226] |
| MOSEI | Both wrong | 129 / 95 | +0.089356 | [+0.057728, +0.119436] |

**关键 contrast**：

- MOSEI corrected − harmed：`+0.067724`，CI `[+0.009628, +0.125607]`。
- MOSI corrected − harmed：`+0.418720`，CI `[+0.220063, +0.735306]`。

解释边界：

- 两个 contrast 的 CI 都高于 0，支持“被 ICD 纠正 polarity 的样本，相较被 ICD 改错的样本，往往伴随更大的 cross-modal fidelity gain”。
- 这是**关联**，不是因果；不能声称“提高 fidelity 就会纠正 polarity”。
- MOSI 的 corrected/harmed 各只有 9 条、6 个源视频 cluster，必须标为小样本探索性证据。
- 总体 Acc-2 不显著：MOSEI Full/ICD `0.872740/0.877608`，McNemar `p=0.5507`；MOSI 两者均 `0.851852`，`p=1.0000`。因此该分析是“错误转移的机制证据”，不是“Acc-2 显著提升证据”。
- corrected 组不是四组中 mean ΔE_cross 最高的组（MOSEI 的 Both correct 更高，MOSI 的 Both correct 也更高）；因此不能把 contrast 写成“corrected 组 fidelity 最高”。

### 9.5 效率与部署成本（MOSEI，同一块 RTX 6000D）

| Model | 部署参数 | 可训参数 | Peak GPU (GiB) | Model-only p50 / p95 (ms) | E2E p50 / p95 (ms) | E2E utt/s | 90 条诊断 MAE |
|---|---:|---:|---:|---:|---:|---:|---:|
| Qwen3-Omni Teacher + Probe | 31.720B | 0（冻结） | 67.526 | 435.32 / 2103.59 | 888.47 / 4449.77 | 0.735 | 0.548651 |
| Full KD Student | 819.309M | 42.650M | 2.091 | 94.36 / 126.75 | 482.97 / 1472.69 | 1.630 | 0.552137 |
| ICD Student | 819.309M | 42.650M | 2.091 | 95.36 / 126.48 | 486.46 / 1471.17 | 1.630 | 0.557631 |

- 参数压缩 `38.72×`；batch-1 峰值显存压缩 `32.29×`；model-only p50 快约 `4.6×`、p95 快约 `16.6×`；E2E 吞吐约 `2.22×`。
- Teacher 的 `31.720B` 是部署参数；按“全部非 expert 参数 + 每层 8/128 routed expert”计算的 architecture-equivalent active 参数为 `4.541B`。这不是“每个多模态 token 实际触及参数数”的严格计数，引用时必须连同定义报告。

### 9.6 视频链路：为什么视觉收益弱

- 早期 benchmark500 的教师**直接生成**通道中，视频单模态 V 分数有 `91.6%` 为 0，V MAE `0.9673`，Acc-2 `53.57`；TAV MAE `0.7995`，并不比 T 单独好多少。这说明当时不是“视频没用”，而是视频输入/生成通道坏了。
- 改为 hidden-state Probe 后，MOSEI teacher V MAE 降到 `0.7198`（仍是七个子集最差），MOSI V MAE `1.4046`（几乎不可用）；TAV 为 `0.4339` / `0.4889`。视觉信息在多模态子集中有贡献，但单模态视觉很弱。
- 视频采样：16 帧覆盖整段；train/valid 窗口时长中位数 6.468 s，P95 16.96 s；约 `39.6%` 超过 7.5 s，`7.53%` 超过 15 s。相邻采样帧间隔约 `duration/15`，短表情变化可能被漏掉。
- 现有预处理为中心裁剪，不能保证保留说话人面部；审计建议做人脸/上半身稳定视图、多短 clip、视频末端轻量微调，但这些不是本轮已完成的主实验。
- 结论：**视频是当前 TAV 系统的短板；ICD 的交互收益主要来自 T/A 及 TA 坐标，不能把 TAV 的收益平均归因到三个模态。**

### 10.2 关键教训

1. **交互重建改善不自动转化为任务改善。** Stage A/C 中 E_pair 大幅改善（`0.3905→0.2519` 等），但 MAE 没有稳定下降。ICD 的机制证据必须与任务证据分开陈述。
2. **验证集选模与测试集表现可能反向。** P0 的 M6 valid 最低、test 最差；Decision ICD 的 test MAE 改善但验证初筛失败；MOSI 的 Uniform Acc-2 选模测试反而更差。不能用一个 split 的结果替代另一个 split 的结论。
3. **小验证集放大 seed 方差。** MOSI validation 只有 229 条（非零 216），First-order test MAE SD `0.0450`；任何 14 方法筛选都存在选择偏差。
4. **“任意固定正交基”是强对照。** Random Orthogonal 在 MOSEI 的 MAE 仅比 ICD 高 `0.0005`，在 MOSI 反而最低（`0.7169`）。如果只用任务 MAE，无法证明语义交互基的独特性；必须报告交互重建。
5. **集成是强替代解释。** MOSI 上 Ensemble 的 Acc-2/F1 最高（`85.11/85.17`），MOSEI seed13 Ensemble 也比 ICD 差但差距不大。必须保留 Ensemble Full KD 作为控制。
6. **显式架构不是监督的替代。** Explicit Full KD 在 MOSEI 比隐式 ICD 差 `0.0059`（0/3 改善），MOSI 显式 ICD 也未优于同架构 Full KD。把交互写进架构不等于把交互蒸馏进学生。
7. **预注册门槛必须保留失败记录。** Decision ICD 的 test 改善没有让项目追认候选；MOSI research 的 scrambled-routed 次策略 Acc-2 最高但主策略失败，没有被事后替换主指标。这是本项目方法学上最重要的纪律。

## 11. 总体结论：可以/不可以声称什么

### 11.1 可以支持的结论

| # | 结论 | 证据强度 |
|---:|---|---|
| 1 | 30B 教师监督明显优于 Student-only；Full KD 在 MOSEI 三 seed 上 MAE `-0.0569`、Acc-2 `+2.04pp` | 强（3 seeds，方向一致） |
| 2 | T/A/V LoRA 适配是 Full KD 之外最稳定、幅度最大的增益来源；Stage D 中 Full+LoRA 比 Full KD 低 `0.0344` MAE | 强（3 seeds，方向一致） |
| 3 | ICD 能明显改善教师交互结构重建：MOSEI `0.4486→0.2669`，MOSI `1.1438→0.5384` | 强（机制层，统一坐标系） |
| 4 | 在 MOSEI 三 seed 均值上，ICD 的 MAE/Pearson/Acc-2/F1 都优于 Full KD；Pearson 3/3 seed 改善 | 中（均值方向一致，但 MAE 仅 2/3，差值小于 SD） |
| 5 | 在 MOSI 三 seed 上，ICD 的 Acc-2 3/3 seed 改善约 `0.86pp`，但 MAE 2/3 退化 | 中（指标权衡，不是全面胜利） |
| 6 | ICD 与 Full KD 的参数量、显存、吞吐相同；训练墙钟 multiplier `0.998×` | 强（实测） |
| 7 | 被 ICD 纠正 polarity 的样本相较被改错样本有更大的 cross-modal fidelity gain | 中（关联；MOSI n 很小） |
| 8 | SIMS/SIMS v2 上 ICD 的三种子平均 MAE 最低（`0.3947` / `0.3398`） | 中（3 seeds，但主表仅 seed13；差值小于部分 SD） |
| 9 | 外部 KD 基线（Projector/EA-KD/CMAD）不弱；Projector 在 MOSEI seed13 与 ICD MAE 持平 | 中（仅 seed13） |

### 11.2 不可以支持的结论

| # | 不可以声称 | 原因 |
|---:|---|---|
| 1 | “ICD 在所有数据集、所有指标上全面最优” | MOSI MAE 不如 Full KD/Random；SIMS 的 Acc-2/F1 与 SIMS v2 的 Acc-5 也有被其他方法超过的项 |
| 2 | “ICD 显著优于 Full KD / Random / Subset-7” | MOSEI 差值小于 seed SD，逐 seed 仅 2/3；无正式显著性 |
| 3 | “语义交互基优于任意正交基” | Random Orthogonal 的任务 MAE 与 ICD 基本持平；只有交互重建支持语义基 |
| 4 | “R×U 加权是必要创新” | M6 valid 最低但 test 最差；RDID-v2 的 U-only 最好；R×U 无稳定泛化 |
| 5 | “提高交互保真度必然提升每个样本的任务预测” | 连续 fidelity gain 与 ΔMAE 的 Spearman CI 跨 0；强度分层结果不一致 |
| 6 | “cross-modal fidelity 导致 polarity 纠正” | 只有分组关联；MOSI corrected/harmed 各 9 条、6 cluster；Acc-2 McNemar 不显著 |
| 7 | “30B 教师是理论上界” | 教师也受标签噪声/Probe 容量限制；且 teacher test 与 student 评测口径需分开 |
| 8 | “SIMS 结论与 MOSI/MOSEI 可直接合并” | 标度、分类头、split、训练预算不同；MAE 不可跨标度比较 |
| 9 | “梯度投影/坐标兼容加权已经是新方法” | 只有 MOSI 单数据集开发筛选；梯度投影 test 仅 2/3 seed 改善；未跨数据集确认 |
| 10 | “Decision ICD 的 test 改善证明方法有效” | 验证初筛失败；test 是后补的，不是盲测 |

### 11.3 推荐的论文主表述

> Interaction Coordinate Distillation (ICD) 在不增加学生参数、显存或端到端吞吐成本的前提下，明显改善了教师多模态交互结构的恢复；在 MOSEI 三种子上带来方向一致的 MAE/Pearson/Acc-2 改善，在 MOSI 上主要改善 polarity 但以 MAE 为代价；在 SIMS/SIMS v2 上取得最低的平均 MAE（主表单 seed、消融三种子）。ICD 的任务收益是数据集和指标相关的，不能简化为“全面优于 Full KD”；其最稳健的证据是交互重建与效率，而不是单一任务指标的显著提升。

## 12. 限制与风险

1. **测试集已被反复观察。** 历史上存在逐 epoch test sweep / test-best 诊断；虽然后续统一为 validation-selected，且重新汇总不读取 test 选模，但“test 已被看过”的事实不能消除。正式论文应把 test 结果标为“报告集”，而不是“从未接触的盲测”。
2. **外部 KD 基线只有 seed13。** Projector/EA-KD/CMAD 和 Adapted Student 没有三种子；不能把它们与 ICD 的三种子均值做正式排名。
3. **MOSEI Ensemble 只有 1/3 seed。** seeds 42/2026 在 epoch 7 暂停；Ensemble 的 `0.4869` 是单 seed，不能与三种子方法直接比较。
4. **MOSI 验证集很小。** 229 条（非零 216）；14 方法筛选和 First-order 的高方差都受此影响。
5. **协议不统一。** `uniform_main_v1` 的早期 test-best 表、`historical_*_seven` 的 valid_mae 表、`mosi_research_14` 的 matched-budget 表不能混用；同一方法在不同表中的数值可能不同（例如 MOSI Uniform `0.7388` vs `0.7332`）。
6. **标准差不是置信区间。** 三种子 `±` 是 sample SD；没有做多重比较校正；多数“均值更好”不能升级为“显著更好”。
7. **视频通道弱。** V 单模态教师 MAE `0.7198`/`1.4046`；16 帧全段采样、中心裁剪、VideoMAE 冻结/仅 LoRA，都是潜在瓶颈；本轮没有完成人脸/多 clip 主实验。
8. **教师不是上界。** 30B + Probe 的 test MAE `0.4429`/`0.4802` 也受标签噪声和 Probe 限制；学生差距不能全部归因于学生容量。
9. **SIMS v2 划分重叠。** 原视频在官方 split 间存在重叠，未重新划分；跨数据集结论需保留这一限制。
10. **未完成/暂停项。** MOSEI Ensemble seeds 42/2026（epoch 7）、RDID-v2 Amplitude×U（19）、research smoke、部分 polarity/video adaptation run 仍为 paused/partial；报告没有把它们当作完成结果。
11. **MAE 不可跨数据集比较。** MOSEI/MOSI `[-3,3]`，SIMS `[-1,1]`；本报告中的跨数据集表格只比较方法内部排序，不比较绝对 MAE。

### 14.1 术语表

| 术语 | 含义 |
|---|---|
| TAV | Text + Audio + Video 完整输入 |

| ICD | Interaction Coordinate Distillation，最终方法；实现名 `uniform_interaction` |
| Uniform | 七个交互坐标等权 |
| R×U | Probe 稳定性 × 训练标签关联加权；不是最终 ICD |
| Full KD | 完整 TAV 输出蒸馏 |
| Ensemble Full KD | 三 Probe 均值/校准概率的 Full KD |
| valid_mae | 按 validation MAE 选 checkpoint |
| valid_acc2_nonzero | 按 validation Acc-2 NZ 选 checkpoint |
| NZ / HZ | 排除 / 保留真实标签 0 的 Acc-2/F1 |
| official test | 官方测试 split；本项目主表只评测选中的 checkpoint |
| test-best | 逐 epoch test sweep 选最优轮；仅历史诊断，不进主表 |
| E_pair | 跨模态 pair 交互重建误差的汇总指标（Stage A/C） |
| E_cross | `(e_TA+e_TV+e_AV+e_TAV)/4` 的跨模态 fidelity 误差 |

### 14.2 数据源优先级

当同一方法在不同文档/目录出现不同数值时，按以下优先级取数：

1. `ICD/ICD.pdf` 与 `docs/paper/icd_experiment_summary.md` 的当前口径（2026-09-24 快照）。
2. `project/reports/all_experiments_dual_checkpoint_20261014/` 的双 checkpoint 重建（本报告主数据源；明确区分 policy 与 campaign）。
3. `outputs/experiments/<experiment_id>/` 的原始 `report.json` / `predictions.jsonl` / `run_config.json`。
4. `project/reports/*.json` 的专项统计（Stage A–D、fidelity、efficiency、teacher test）。
5. `docs/archive/` 的历史快照；只用于追溯，不作为当前结论。

不要做的事：

- 不把 `test-best` 数值混入 `valid_mae` 表。
- 不把不同 campaign 的同名方法直接合并（例如 `uniform_main_v1` 与 `multiseed_controls_v1`）。
- 不把不同标度（`[-3,3]` vs `[-1,1]`）的 MAE 直接比较。
- 不用单一 seed 的最优值替代三种子均值。
- 不把 `±` 当作置信区间或显著性。
