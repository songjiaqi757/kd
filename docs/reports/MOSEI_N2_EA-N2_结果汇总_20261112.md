## 1. 方法与协议

- **N2**：No-CE Uniform ICD，CE=0，交互损失权重 λ=0.30，uniform interaction coordinates。
- **EA_N2**：EA-KD-Full + N2，熵自适应 KD 权重同时作用于回归与分类 KD，再叠加 No-CE Uniform ICD（λ=0.30）。
- Student seed 13；最多 30 epoch，validation patience 7；batch 8，lr `1e-4`。
- MOSEI 使用原始 `[-3,3]` 标度，MAE 在该标度上计算。
- 每个 run 保留 `best_valid_mae.pt` 与 `best_valid_acc2_nonzero.pt`，分别评测一次 official test；`last` 不评测，测试不参与选模。
- Official test：4659 条，其中非零标签 3634 条。MOSEI 主表 Acc-2 使用 **nonzero** 口径。

## 5. 读法

1. **N2 的 MAE 是本批 MOSEI 结果中最低的**：`0.4748`，比原 ICD seed13 的 `0.4774` 低 `0.0026`，比 ICD 三种子均值 `0.4762 ± 0.0045` 低 `0.0014`，也低于此前最好的 Random Orthogonal `0.4767 ± 0.0031`。但差距远小于 seed SD，且只有单 seed，**只能作为探索性候选，不能写成已确认超越**。
2. **EA_N2 在 Acc-2 选模下取得最高分类指标**：Acc-2 `88.30`、F1 `88.23`、Acc-7 `57.48`，但 MAE `0.4776` 与原 ICD seed13 `0.4774` 基本持平，且不如 N2 的 `0.4748`。这是“MAE vs 分类指标”的权衡，不是全面占优。
3. **没有证据表明 EA + N2 组合稳定优于单独 N2**：N2 在 MAE/Pearson 上更好，EA_N2 只在 Acc-2/F1/Acc-7 上更好；两者各有胜负。
4. **相对 Full KD 三种子均值（MAE `0.4798`、Acc-2 `87.28`）两者方向一致更好**：N2 `0.4748 / 87.95`，EA_N2 `0.4776 / 88.30`；但单 seed 与三种子均值不可直接做显著性比较。
5. **选模敏感性明显**：N2 在 `valid_mae` 选模下 MAE `0.4748`，在 `valid_acc2` 选模下恶化到 `0.4829`；EA_N2 则相反，`valid_acc2` 选模的 MAE `0.4776` 优于 `valid_mae` 的 `0.4800`。报告时必须注明选模口径。
6. 结论标签：**单 seed、探索性，未确认**。需要同协议、预注册的三种子复验，且不应继续用 test 结果反向挑方法。
