## 1. 执行摘要

### 1.1 十项总判断

1. **教师监督本身有效，且 T/A/V LoRA 是除蒸馏外最稳定的增益来源。** MOSEI 上 Full KD 相对 Student-only 的 official-test MAE 从 `0.5367` 降到 `0.4798`（`-0.0569`），Acc-2 从 `85.24` 升到 `87.28`；Stage D 中 Full KD + LoRA 相对 Full KD 再降 `0.0344` MAE，三种子方向一致。
2. **ICD 最稳健的优势仍然是机制层，而不是所有数据集的任务指标。** 七坐标交互重建 MAE 从 Full KD 的 MOSEI `0.4486` / MOSI `1.1438` 降到 ICD 的 `0.2669` / `0.5384`；这一结论在统一 Anchored Möbius 坐标系下可复现。
3. **MOSEI 上 ICD 的三种子任务均值略优于 Full KD，但未达到稳定显著。** ICD `0.4762 ± 0.0045` vs Full KD `0.4798 ± 0.0019`，MAE 仅 2/3 seed 改善，差值小于 seed 间标准差；Pearson 3/3 改善（`+0.0067`）。显式 ICD 更低到 `0.4756 ± 0.0015`，但同样不能称为显著胜出。
4. **MOSI 上原始 ICD 的任务 MAE 不如 Full KD。** 七方法三种子：ICD `0.7388 ± 0.0141` vs Full KD `0.7316 ± 0.0056`（高 `0.0072`，仅 1/3 seed 改善）；但 ICD 的 Acc-2 在 3/3 seed 改善约 `0.86pp`。这是一个明确的指标权衡，不是全面胜利。
5. **2026-11-08 至 11-11 的 MOSI 新实验改变了“最佳配置”的排序，但没有改变“需要多种子确认”的结论。** 单 seed、validation 选模、official-test 仅报告的探索性结果中，`E3_ea_kd_full` 达到 `0.6683` test MAE，`E4_weight050` 为 `0.6800`，`F7_icd_no_ce_lambda025` 为 `0.6812`；而原始 ICD 同批约 `0.734`。这些是**单 seed 探索性**数字，不能直接写成 ICD 的确认性提升。
6. **MOSI 上真正的强候选来自“去掉 Task CE + 降低 ICD 强度”，而不只是 ICD 结构本身。** 确认性 F 系列显示：`F7`（CE=0，λ=0.25，ICD）test MAE `0.6812`，`F1`（CE=0，λ=0，Full KD）`0.7091`，`F0`（CE=0.5，λ=0，Full KD）`0.7174`。No-CE 对 Full KD 和 ICD 都有帮助，因此不能把收益全部归因于 ICD；在 CE=0、λ=0.25 下 ICD 相对 Full KD 的额外收益约 `0.028` MAE，但只有单 seed。
7. **外部 KD 方法在 MOSI 上重新成为最强单 seed 候选。** 方法搜索中 `E3_ea_kd_full`（熵自适应权重同时作用于回归和分类 KD，不含 ICD）test MAE `0.6683`、Acc-2 `86.89`；其 validation MAE `0.7316` 并非最低（最低为 `V1_uniform_a050` 的 `0.7221`），说明 validation 排名与 test 排名再次不一致。
8. **SIMS / SIMS v2 仍是 ICD 最干净的外部有效性证据，但 11-11 的 N2 已在 SIMS v2 单 seed 上略低于原 ICD。** 三种子消融中 ICD 平均 MAE 最低：SIMS `0.3947`，SIMS v2 `0.3398`；主表 seed13 为 `0.3866` / `0.3396`。11-11 的 N2 / EA-N2（30 epoch、单 seed）在 SIMS 上为 `0.4103–0.4201`，没有超过原 ICD；在 SIMS v2 上 `N2_sims_v2` 为 `0.3358`，比原 ICD `0.3396` 低 `0.0038`，但协议不同且只有单 seed，不能当作确认性超越。
9. **效率结论不变：ICD 不增加部署成本。** ICD 与 Full KD 均为 `819.309M` 部署参数、`42.650M` 可训参数、batch-1 峰值 `2.091 GiB`、model-only p50 约 `95 ms`、E2E `1.630 utt/s`；训练墙钟 multiplier `0.998×`。
10. **负结果与方法学纪律仍然是项目最重要的资产之一。** equal-modality 六变体、Decision ICD、按阶数路由、DGL 适配、显式交互架构、R×U 加权都没有稳定超过原 ICD；项目保留了初筛失败记录，没有事后改门槛。

## 2. 研究目标、方法与协议

### 2.1 核心命题

项目检验的不是“大模型教师是否比小模型强”，而是：

> 在固定学生架构、输入、可训练适配范围和评测协议的前提下，把 30B 教师的监督从“只匹配完整 TAV 输出”改为“匹配教师的多模态交互坐标”，能否带来更稳定、更可解释的情感预测收益。

这一问题被拆成三层对照：

| 层 | 对照 | 回答的问题 |
|---|---|---|
| 监督量 | Adapted Student vs Full KD vs Subset-7 | 收益是否只是“多给了教师监督”？ |
| 监督组织 | Subset-7 vs First-order vs First+Second-order vs Uniform ICD vs Random Orthogonal | 收益是否来自交互坐标这一特定基，而不是任意七维线性变换？ |
| 选择性加权 | Uniform ICD vs R-only / U-only / R×U | Probe 稳定性 R 与任务关联 U 是否必要？ |

### 2.2 教师侧

- 教师模型：`Qwen3-Omni-30B-A3B-Instruct`，15 个权重分片，BF16，双卡 model-parallel 前向。
- 输入：完整 TAV 以及七个非空模态子集 `T / A / V / TA / TV / AV / TAV`。
- 特征：最后一个有效输入 token 的 Thinker hidden state，维度 `2048`，FP16 缓存。
- Probe：`LayerNorm(2048) → Linear(2048,512) → GELU → Dropout(0.1)`，接七分类头与标量回归头 `3·tanh(Linear(512,1))`。
- Probe 种子：`2026 / 2027 / 2028`；AdamW，lr `1e-3`，weight decay `1e-4`，batch `128`；损失为 weighted Smooth-L1 + `0.5 ×` 七分类 CE；最多 200 epoch，patience 25。
- 选模：official validation 的 joint loss 最小；seed2026 固定用于单 Probe TAV 目标，三个 Probe 的均值/方差用于交互目标与 ensemble 目标。
- 温度校准：validation NLL 上拟合标量温度。MOSEI 三个 Probe 为 `1.0115 / 1.0668 / 1.0081`；MOSI 为 `1.1912 / 1.2059 / 1.1803`。
- 关键边界：三个 Probe 不是三个独立的大模型教师；它们共享同一教师的特征缓存。

### 2.3 学生侧

| 模态 | 编码器 | 适配 |
|---|---|---|
| Text | `Qwen3-0.6B-Base` | T/A LoRA，rank 8 |
| Audio | `WavLM-Base-Plus` | T/A LoRA，rank 8 |
| Video | `VideoMAE-Base`（Kinetics-400 自监督） | 视频末端 12 层 LoRA，rank 8，alpha 16，dropout 0.05 |

- 融合：每个样本只做一次 T/A/V 编码，七种模态子集复用同一组编码表示，通过模态屏蔽构造七个子集的前向。
- 推理：只使用完整 TAV，不集成七个子集预测，也不加载教师。
- 参数量：部署 `819.309M`；可训 `42.650M`（T/A/V LoRA + 池化/融合/预测头）。
- 训练：AdamW，lr `1e-4`，weight decay `0.01`，batch size `8`；主实验 20 epoch 固定预算（P0 早期协议为最多 30 epoch、patience 7、min_epochs 8）；SIMS 为 `min_epochs=20, patience=20`，不早停；新 MOSI campaign 使用 30–50 epoch、patience 7–8 不等。
- 损失：`L_task + L_reg + L_KL`，其中 `L_task` 含回归 + `0.5 ×` 七分类 CE；`kd_temperature=2.0`。

### 2.4 交互坐标与 ICD 损失

对任意子集 `S`，教师 Probe 给出预测 `f_t(S)`；学生给出 `f_s(S)`。基线 `b` 取每个 Probe 在 official train 上完整 TAV 的平均预测，学生使用三个教师基线的均值。Anchored Möbius 分解为：

```text
I(T)   = f(T) - b
I(A)   = f(A) - b
I(V)   = f(V) - b
I(TA)  = f(TA) - f(T) - f(A) + b
I(TV)  = f(TV) - f(T) - f(V) + b
I(AV)  = f(AV) - f(A) - f(V) + b
I(TAV) = f(TAV) - f(TA) - f(TV) - f(AV) + f(T) + f(A) + f(V) - b
```

七个原始子集分数与七个交互坐标在给定 `b` 下可互相转换；变换本身不增加教师信息，改变的是**监督的组织方式**。

公共损失：

```text
L_base = L_task + λ_full · L_reg(TAV) + λ_full · L_KL(TAV)
L_ICD  = L_base + λ_interaction · mean_k w_k · SmoothL1(I_s,k, I_t,k)
```

- `λ_full = 1.0`，`λ_interaction = 1.0`，`alpha_ce = 0.5`（新 MOSI campaign 对 CE 与 λ 做了系统扫描）。
- Uniform ICD：`w_k = 1/7`。
- R×U：`R_k = |mean(I_k)| / sqrt(var(I_k)+1e-4)`，`U_k = max(|Pearson(I_k, y_train)|,0.01)` 后均值归一化，`w_k ∝ R_k·U_k`，再做逐样本均值归一化与 `[0.25,4.0]` 截断。
- 关键解释边界：`U` 是训练标签关联代理，不是因果 utility；`R` 同时包含交互幅度与 Probe 间稳定性，不是纯不确定性；`R×U` 不是最终 ICD，`M4 = Uniform Interaction` 才是最终方法。

### 2.5 方法族

| 方法 | 额外目标 | 说明 |
|---|---|---|
| Adapted Student | 无 | 与 M3/M4/M6 相同 T/A/V LoRA 适配范围，只训练任务损失 |
| Full KD | 完整 TAV 回归 + 分类 | 单 Probe（seed2026） |
| Ensemble Full KD | 完整 TAV 回归 + 分类 | 三个 Probe 校准概率/分数的均值 |
| Subset-7 KD | 七个子集原始预测 | 均匀权重，直接匹配 |
| First-order Interaction | 仅 `T/A/V` 三个一阶坐标 | 均匀权重 |
| First+Second-order | 一阶 + 二阶（`TA/TV/AV`） | 不含三阶 |
| Uniform Interaction (ICD) | 七个交互坐标 | 均匀权重 |
| Random Orthogonal | 七个随机正交坐标 | 固定坐标随机种子 `20260922`，不随训练 seed 变化 |
| Projector Feature KD | 学生融合表示投影到教师 2048 维 | AAAI 2024 适配 |
| EA-KD | 熵加权分类蒸馏 | ICCV 2025 适配，`log(7)` 上界 |
| EA-KD-Full | 熵加权同时作用于回归与分类 KD | 2026-11 新候选；MOSI 单 seed test `0.6683` |
| CMAD-style CAFD | 逐样本特征 MSE + 跨样本相关 + 双向 KL | ICCV 2025，仅 CAFD，不含 MAR |
| RLD / SKD | 可靠标签蒸馏 / 选择性知识蒸馏 | 2026-11 方法搜索新增，未超过领先候选 |
| Coordinate-compatible | 用 task 与各坐标的梯度余弦构造权重 | 2026-10 起的新变体 |
| Absorbability | 兼容性 + 进度/难度信号的 EMA 门控 | 2026-11 方法搜索新增 |
| Consistency | 回归分数与七分类期望值的一致性惩罚 | 2026-11 方法搜索新增 |

### 2.6 数据与评测协议

| 数据集 | Train | Valid | Test | 标签范围 | 备注 |
|---|---:|---:|---:|---|---|
| CMU-MOSEI | 16,326 | 1,871 | 4,659 | `[-3,3]` | 22,856 utterances；train+valid 窗口 18,278 |
| CMU-MOSI | 1,284 | 229 | 686 | `[-3,3]` | 2,199 utterances；test 非零标签 656 |
| SIMS | 1,368 | 456 | 457 | `[-1,1]` | 官方 CSV 划分，原生标度 |
| SIMS v2 有标注集 | 2,722 | 647 | 1,034 | `[-1,1]` | 完整 `meta.csv` 4,403 条中仅有标注 clip；保留官方划分 |

- MOSEI/MOSI 使用官方 split，不重新划分；`official_test_windowed.jsonl` 为长样本窗口化后的测试清单。
- 超过 30 秒的样本按最长 30 秒、重叠 5 秒切窗，并用重叠校正权重聚合到 utterance。
- 500 条教师基准来自 500 个不同源视频，train/valid 为 450/50；测试集不参与教师基准。
- SIMS v2 记录了原视频在 split 间的重叠，但不重新划分；这是跨数据集结论的一个限制。

| 指标 | 定义 |
|---|---|
| MAE | 连续情感分数平均绝对误差；MOSEI/MOSI 为 `[-3,3]`，SIMS 为 `[-1,1]`，不可跨标度直接比较 |
| Pearson | 预测与真实分数的 Pearson 相关 |
| Acc-2 NZ / F1 NZ | 排除真实标签为 0 的 Acc-2 / weighted F1 |
| Acc-2 HZ / F1 HZ | 保留真实标签为 0 的 Acc-2 / weighted F1 |
| Acc-7 | 七分类准确率（MOSEI/MOSI） |
| Acc-3 / Acc-5 | SIMS 的三档/五档准确率；SIMS 官方 Acc-2 将 `<=0` 作为非正类 |
| 交互重建 MAE | 七坐标 `(3×First + 3×Second + Third)/7`，统一后验到同一 Anchored Möbius 坐标系 |

`±` 一律为 seed 的样本标准差（sample SD），不是置信区间，也不是三个模型预测的 ensemble。

### 2.7 Checkpoint 选模与统计口径

项目在 2026-10 后统一采用**双 checkpoint**口径：

- `best_valid_mae.pt`：official validation MAE 最小；并列取最早 epoch。
- `best_valid_acc2_nonzero.pt`：official validation Acc-2 NZ 最大；并列取最早 epoch。
- `best.pt` 指向 MAE 最优；`last.pt` 只用于续训。

## 4. 结果：CMU-MOSEI

### 4.1 P0 主实验（M0 / M1 / M3 / M4 / M6，三种子）

协议：official validation 选模（valid_mae），仅评测 selected checkpoint；seeds 13/42/2026。

**Official-test 均值 ± 样本标准差**

| 方法 | MAE ↓ | Pearson ↑ | Acc-2 NZ ↑ | F1 NZ ↑ | Acc-7 ↑ |
|---|---:|---:|---:|---:|---:|
| M0 冻结 TAV Student-only | 0.536696 ± 0.008767 | 0.767649 ± 0.005771 | 85.2412 ± 0.8165 | 85.2107 ± 0.7002 | 53.8814 ± 1.5761 |
| M1 冻结 TAV Full KD | 0.527306 ± 0.002139 | 0.776850 ± 0.004184 | 84.8101 ± 0.5250 | 84.8309 ± 0.3787 | 54.3035 ± 0.2888 |
| M3 Full KD + T/A/V LoRA | 0.479825 ± 0.001906 | 0.816943 ± 0.004237 | 87.2776 ± 0.6062 | 87.2778 ± 0.5701 | 56.9793 ± 0.4943 |
| **M4 ICD（Uniform Interaction）** | **0.476242 ± 0.004540** | **0.823668 ± 0.001264** | **87.7821 ± 0.4429** | **87.7321 ± 0.4238** | **57.1367 ± 0.3611** |
| M6 R×U Interaction | 0.481887 ± 0.000657 | 0.819403 ± 0.000701 | 87.4152 ± 0.6349 | 87.4376 ± 0.5601 | 56.8076 ± 0.3971 |

关键读法：

- **Full KD 相对 Student-only 的增益最大。** M0→M3 的 test MAE 从 `0.5367` 降到 `0.4798`（`-0.0569`），Acc-2 从 `85.24` 升到 `87.28`。这确认了教师监督本身有效。
- **M4（ICD）在 test 上最优，M6（R×U）在 valid 上最优。** M4 test MAE `0.4762` 比 M3 `0.4798` 低 `0.0036`；但 M4 valid MAE `0.4698` 比 M3 `0.4671` 高 `0.0027`。M6 valid `0.4640` 最低，但 test `0.4819` 退化。这是“valid 最优不等于 test 最优”的典型案例，也是最终选择 M4 而非 M6 的原因。
- **M4 相对 M3 的优势不是 3/3 seed。** 逐 seed 看 MAE 仅 2/3 改善（seed13 `-0.004268`、seed42 `-0.006583`、seed2026 `+0.000100`），且差值小于 seed SD。

**配对差异（ICD − Full KD，official test）**

| 指标 | Seed 13 | Seed 42 | Seed 2026 | 均值差 | 改善 seeds |
|---|---:|---:|---:|---:|---:|
| ΔMAE | -0.004268 | -0.006583 | +0.000100 | **-0.003584** | 2/3 |
| ΔPearson | +0.009611 | +0.007085 | +0.003479 | **+0.006725** | 3/3 |
| ΔAcc-2 (pp) | +1.3208 | -0.6604 | +0.8531 | **+0.5045** | 2/3 |
| ΔF1 (pp) | +1.2288 | -0.6608 | +0.7949 | **+0.4543** | 2/3 |

结论：ICD 在 Pearson 上 3/3 seed 改善，但 MAE/Acc-2/F1 只有 2/3；所有差值都远小于 seed 间标准差。**最稳妥的表述是“均值方向一致改善，但未达到稳定显著”。**

### 4.2 七方法三种子对照（MOSEI）

协议：`valid_mae` 选模，official test；六方法 3 seeds，Ensemble 仅 seed13。`±` 为 seed 样本标准差。

| 方法 | MAE ↓ | Pearson ↑ | Acc-2 NZ ↑ | F1 NZ ↑ | seeds |
|---|---:|---:|---:|---:|---:|
| Full KD | 0.4798 ± 0.0019 | 0.8169 ± 0.0042 | 87.28 ± 0.61 | 87.28 ± 0.57 | 3/3 |
| Subset-7 KD | 0.4780 ± 0.0044 | 0.8196 ± 0.0039 | 87.61 ± 0.33 | 87.52 ± 0.32 | 3/3 |
| First-order Interaction | 0.4814 ± 0.0037 | 0.8186 ± 0.0020 | 87.19 ± 0.73 | 87.21 ± 0.67 | 3/3 |
| First+Second-order | 0.4780 ± 0.0007 | 0.8215 ± 0.0023 | 87.47 ± 0.21 | 87.46 ± 0.14 | 3/3 |
| Random Orthogonal | 0.4767 ± 0.0031 | 0.8219 ± 0.0037 | 87.62 ± 0.77 | 87.62 ± 0.75 | 3/3 |
| **Uniform Interaction (ICD)** | **0.4762 ± 0.0045** | **0.8237 ± 0.0013** | **87.78 ± 0.44** | **87.73 ± 0.42** | 3/3 |
| Ensemble Full KD | 0.4869 | 0.8172 | 87.84 | 87.84 | 1/3 |

解读：

1. **ICD 的 MAE 均值最低，但与 Random Orthogonal 的差距只有 `0.0005`**，远小于两者 seed SD（`0.0045` / `0.0031`）。不能据此声称“语义交互基显著优于随机正交基”。Random 的价值在于提供了一个强对照：任意固定正交基也能获得相近的任务 MAE，因此 ICD 的独特性必须由交互重建证据而非单一任务 MAE 支撑。
2. **Subset-7 与 First+Second 的 MAE 与 ICD 基本同档**（`0.4780` vs `0.4762`）。这说明“多子集监督”本身贡献很大；把七个原始预测换成七个交互坐标，带来的任务增益很小。
3. **First-order 单独使用并不差**（`0.4814`），但也没有超过 Full KD。跨模态高阶项不是任务 MAE 的必要条件。
4. **ICD 的 Pearson 均值最高**（`0.8237`），且在 3/3 seed 上相对 Full KD 改善 Pearson。这支持“交互坐标改善了连续排序结构”，但不足以支持“所有任务指标全面最优”。
5. **Ensemble 只有 1 seed，且 MAE 最差**（`0.4869`）。这削弱了“简单三 Probe 集成就能解释 ICD 收益”的替代解释，但还不能替代完整的 ICD-single 2×2 因子实验。

目的：固定 T/A/V 三条模态路径、LoRA 范围、池化维度、优化器、batch、epoch、教师资产与 seed 集，只改训练规则或显式融合结构，检验 ICD 的增益是否来自某个可替换组件。

- **没有任何变体在三种子上稳定优于原 ICD。** 最好的 Explicit Uniform 平均 MAE 低 `0.00055`，但只有 2/3 seed 改善；Gradient-projected 的 Acc-2 均值最高（`87.91`），但 MAE 略差且只有 1/3 seed 改善。
- **显式交互融合架构（Explicit Full KD）反而比隐式 ICD 差 `0.0059`（0/3 改善）**，说明“把交互结构写进架构”不能替代“用教师交互坐标做监督”。
- **Shared-dropout 稳定变差（0/3 改善）**，说明七个子集共享同一 dropout realization 会削弱监督信号，而不是提供正则。
- 因而，equal-modality v3 的结论是**负结果**：原 ICD 的简单均匀七坐标目标已经是一个很强的基线，额外规则没有带来可复现增益。

> `equal_modality_extensions_v2` 是 epoch 1 后停止的早期试跑，未进入上表；正式结果为 v3。

### 6.1 协议

SIMS 与 SIMS v2 使用各自官方 CSV 划分、教师资产与训练输出，独立于 MOSI/MOSEI：

- 与 MOSEI/MOSI 不同，SIMS 的 Full KD 与 ICD 都是 `valid_mae` 主策略；没有 test-best 混入。

### 6.4 2026-11-11 N2 / EA-N2 迁移结果

`N2` = No-CE、λ=0.30、Uniform ICD；`EA_N2` = EA-KD-Full + N2 组合。均为 seed13、30 epoch、patience 7；SIMS/SIMS v2 使用 native 标度与五分类头。SIMS 的 `Acc-2 primary` 是官方零包含口径，`Acc-2 NZ` 另行列出，二者不可混用。

| Dataset | Run | Selection | Epoch | MAE | Acc-2 primary | Acc-2 NZ | F1 primary | Pearson |
|---|---|---|---:|---:|---:|---:|---:|---:|
| SIMS | EA_N2_sims | valid_mae | 19 | 0.4103 | 75.71 | 79.12 | 76.32 | 0.6017 |
| SIMS | N2_sims | valid_mae | 16 | 0.4108 | 77.90 | 79.12 | 78.12 | 0.6088 |
| SIMS | N2_sims | valid_acc2 | 15 | 0.4151 | 79.87 | 79.38 | 79.23 | 0.6243 |
| SIMS | EA_N2_sims | valid_acc2 | 17 | 0.4201 | 78.77 | 78.87 | 78.52 | 0.6011 |
| SIMS v2 | EA_N2_sims_v2 | valid_mae | 8 | 0.3507 | 78.63 | 81.12 | 78.63 | 0.6760 |
| SIMS v2 | EA_N2_sims_v2 | valid_acc2 | 15 | 0.3681 | 77.66 | 78.05 | 77.10 | 0.6878 |
| **SIMS v2** | **N2_sims_v2** | valid_mae | **28** | **0.3358** | 79.40 | 82.55 | 79.50 | 0.6913 |
| SIMS v2 | N2_sims_v2 | valid_acc2 | 23 | 0.3561 | 78.53 | 79.25 | 78.23 | 0.6852 |

读法：

- **SIMS 上 N2/EA-N2 的 `0.4103–0.4201` 没有超过原 ICD 的 seed13 `0.3866` / 三种子 `0.3947`。** SIMS v2 上则出现了分化：`N2_sims_v2` 的 valid_mae test MAE 为 `0.3358`，低于原 ICD 的 `0.3396` / `0.3398`；`EA_N2_sims_v2` 的 `0.3507` 仍高于原 ICD。
- **`N2_sims_v2` 的 `0.3358` 是这批唯一低于原 ICD 的新结果，但它只有单 seed，且训练协议为 30 epoch / patience 7；原 ICD 是 20 epoch 固定、`patience=20`。** 不能把 `0.0038` 的差距写成“已确认超越”。
- **EA-N2 没有显示出“组合一定更好”**：SIMS 上 N2 的 Acc-2 primary（`77.90`）高于 EA_N2（`75.71`）；SIMS v2 上 N2（`0.3358`）也低于 EA_N2（`0.3507`）。目前没有证据支持 EA+ICD 组合优于单独 N2。
- 结论应分开写：**SIMS 上 N2/EA-N2 未复现原 ICD 优势；SIMS v2 上 N2 取得单 seed 新低，但需同协议三种子复验。** 不能写成“ICD 在 SIMS 上失效”，也不能写成“N2 已确认超过 ICD”。

### 6.5 SIMS 小结

| 问题 | 答案 |
|---|---|
| ICD 能否迁移到 SIMS？ | 能。主表与消融的 MAE 均值都是最低，Pearson 也最高。 |
| 是否全面最优？ | 不是。SIMS 的 Acc-2/F1 低于 First+Second；SIMS v2 的 Acc-5 低于 First+Second。 |
| 是否显著？ | 未做正式显著性；均值差与 seed SD 有重叠，不能称为稳定显著。 |
| 与 MOSI/MOSEI 的差别？ | SIMS 原生 `[-1,1]`、五分类头、20 epoch 不早停；是独立实现，不是简单换标签。 |
| 2026-11 的 N2/EA-N2 如何？ | SIMS 上未超过原 ICD；SIMS v2 的 N2 单 seed `0.3358` 略低于原 ICD `0.3396`，但 30 vs 20 epoch、未多种子，不能确认。 |

### 7.4 Cross-modal fidelity 与 polarity outcome

定义 `E_cross=(e_TA+e_TV+e_AV+e_TAV)/4`，`ΔE_cross=E_cross,Full−E_cross,Uniform`；正值表示 ICD 恢复了更多教师跨模态交互结构。

**连续误差诊断**

| 数据集 | Mean ΔE_cross | Mean ΔM | Spearman ρ | Video-cluster 95% CI |
|---|---:|---:|---:|---:|
| MOSEI | +0.211872 | -0.003293 | +0.0118 | [-0.0333, +0.0589] |
| MOSI | +0.736032 | -0.031203 | +0.0271 | [-0.0916, +0.1379] |

连续 fidelity gain 与任务误差改善**没有显著单调关系**（两个 CI 都跨 0）。

**Polarity outcome 分组（组内 mean ΔE_cross）**

| 数据集 | Outcome | N / video clusters | Mean ΔE_cross | Cluster-bootstrap 95% CI |
|---|---|---:|---:|---:|
| MOSEI | Full wrong → ICD correct | 54 / 44 | +0.128126 | [+0.090106, +0.171520] |
| MOSEI | Both correct | 1,208 / 273 | +0.248418 | [+0.231158, +0.266226] |
| MOSEI | Both wrong | 129 / 95 | +0.089356 | [+0.057728, +0.119436] |
| MOSEI | Full correct → ICD wrong | 47 / 42 | +0.060401 | [+0.016308, +0.109611] |
| MOSI | Full wrong → ICD correct | 9 / 6 | +0.612899 | [+0.419113, +0.830056] |
| MOSI | Both correct | 175 / 10 | +0.838131 | [+0.602569, +1.013536] |
| MOSI | Both wrong | 23 / 9 | +0.392014 | [+0.061889, +0.632542] |
| MOSI | Full correct → ICD wrong | 9 / 6 | +0.194179 | [-0.173482, +0.499121] |

**关键 contrast**：

- MOSEI corrected − harmed：`+0.067724`，CI `[+0.009628, +0.125607]`。
- MOSI corrected − harmed：`+0.418720`，CI `[+0.220063, +0.735306]`。

解释边界：

- 两个 contrast 的 CI 都高于 0，支持“被 ICD 纠正 polarity 的样本，相较被 ICD 改错的样本，往往伴随更大的 cross-modal fidelity gain”。
- 这是**关联**，不是因果；不能声称“提高 fidelity 就会纠正 polarity”。
- MOSI 的 corrected/harmed 各只有 9 条、6 个源视频 cluster，必须标为小样本探索性证据。
- 总体 Acc-2 不显著：MOSEI Full/ICD `0.872740/0.877608`，McNemar `p=0.5507`；MOSI 两者均 `0.851852`，`p=1.0000`。因此该分析是“错误转移的机制证据”，不是“Acc-2 显著提升证据”。
- corrected 组不是四组中 mean ΔE_cross 最高的组（MOSEI 的 Both correct 更高，MOSI 的 Both correct 也更高）；因此不能把 contrast 写成“corrected 组 fidelity 最高”。

### 7.6 视频链路：为什么视觉收益弱

- 早期 benchmark500 的教师**直接生成**通道中，视频单模态 V 分数有 `91.6%` 为 0，V MAE `0.9673`，Acc-2 `53.57`；TAV MAE `0.7995`，并不比 T 单独好多少。这说明当时不是“视频没用”，而是视频输入/生成通道坏了。
- 改为 hidden-state Probe 后，MOSEI teacher V MAE 降到 `0.7198`（仍是七个子集最差），MOSI V MAE `1.4046`（几乎不可用）；TAV 为 `0.4339` / `0.4889`。视觉信息在多模态子集中有贡献，但单模态视觉很弱。
- 视频采样：16 帧覆盖整段；train/valid 窗口时长中位数 6.468 s，P95 16.96 s；约 `39.6%` 超过 7.5 s，`7.53%` 超过 15 s。相邻采样帧间隔约 `duration/15`，短表情变化可能被漏掉。
- 现有预处理为中心裁剪，不能保证保留说话人面部；审计建议做人脸/上半身稳定视图、多短 clip、视频末端轻量微调，但这些不是本轮已完成的主实验。
- 结论：**视频是当前 TAV 系统的短板；ICD 的交互收益主要来自 T/A 及 TA 坐标，不能把 TAV 的收益平均归因到三个模态。**

### 8.2 十条方法学教训

1. **交互重建改善不自动转化为任务改善。** Stage A/C 中 E_pair 大幅改善（`0.3905→0.2519` 等），但 MAE 没有稳定下降；MOSI 第一轮 E8b 的七坐标均值最低，任务 MAE 却高于 E2。机制证据必须与任务证据分开陈述。
2. **验证集选模与测试集表现可能反向。** P0 的 M6 valid 最低、test 最差；Decision ICD 的 test MAE 改善但验证初筛失败；2026-11 的 E/F/A/方法搜索中，validation 最优与 test 最优多次不是同一配置。
3. **小验证集放大 seed 方差。** MOSI validation 只有 229 条（非零 216），First-order test MAE SD `0.0450`；任何 14 方法筛选和单 seed 调参都存在选择偏差。
4. **“任意固定正交基”是强对照。** Random Orthogonal 在 MOSEI 的 MAE 仅比 ICD 高 `0.0005`，在 MOSI 反而最低（`0.7169`）。如果只用任务 MAE，无法证明语义交互基的独特性；必须报告交互重建。
5. **集成是强替代解释。** MOSI 上 Ensemble 的 Acc-2/F1 最高（`85.11/85.17`），MOSEI seed13 Ensemble 也比 ICD 差但差距不大。必须保留 Ensemble Full KD 作为控制。
6. **显式架构不是监督的替代。** Explicit Full KD 在 MOSEI 比隐式 ICD 差 `0.0059`（0/3 改善），MOSI 显式 ICD 也未优于同架构 Full KD。把交互写进架构不等于把交互蒸馏进学生。
7. **预注册门槛必须保留失败记录。** Decision ICD 的 test 改善没有让项目追认候选；MOSI research 的 scrambled-routed 次策略 Acc-2 最高但主策略失败，没有被事后替换主指标。这是本项目方法学上最重要的纪律。
8. **No-CE 不是 ICD 专属机制。** 确认性 F 系列中，移除 Task CE 对 Full KD 也有 `-0.0095` 的 MAE 改善；在 CE=0.5 时，ICD 相对 Full KD 的收益接近于零甚至为负。把 No-CE 的收益全部归因于 ICD 会是错误归因。
9. **跨 campaign 的协议漂移会制造“矛盾结果”。** 同一 ICD 在七方法表、第一轮 E0、确认性 F2 中分别为 `0.7388 / 0.7344 / 0.7577`，训练预算、早停、教师资产复用和选模细节不同。报告必须带 campaign 标签，不能把同名方法合并。
10. **单 seed 的“大幅提升”必须降级。** 2026-11 的 `0.6683`、`0.6800`、`0.6812` 都很亮眼，但都是单 seed；其中部分 test 还参与了方法排序。没有三种子配对复验，不能写成稳定提升。

### 9.3 推荐的论文主表述

> Interaction Coordinate Distillation (ICD) 在不增加学生参数、显存或端到端吞吐成本的前提下，明显改善了教师多模态交互结构的恢复；在 MOSEI 三种子上带来方向一致的 MAE/Pearson/Acc-2 改善，在 MOSI 上主要改善 polarity 但以 MAE 为代价；在 SIMS/SIMS v2 上取得最低的平均 MAE（主表单 seed、消融三种子）。ICD 的任务收益是数据集和指标相关的，不能简化为“全面优于 Full KD”；其最稳健的证据是交互重建与效率，而不是单一任务指标的显著提升。

如果要在论文中纳入 2026-11 的 MOSI 调参结果，建议单独列为 **“exploratory single-seed tuning”**，并明确：

1. 这些配置是在已观察 official-test 的项目历史上做的开发搜索，不是盲测；
2. `E3_ea_kd_full` 是外部 KD 基线，不是 ICD 的改进；
3. `F7`（No-CE ICD λ0.25）是当前最值得做三种子配对复验的 ICD 配置；
4. 在任何“ICD 超过 Full KD”的强主张之前，必须补 seeds 42/2026、同协议 Full KD 对照和 source-video clustered 统计。

## 10. 限制与风险

1. **测试集已被反复观察。** 历史上存在逐 epoch test sweep / test-best 诊断；虽然后续统一为 validation-selected，且重新汇总不读取 test 选模，但“test 已被看过”的事实不能消除。正式论文应把 test 结果标为“报告集”，而不是“从未接触的盲测”。
2. **2026-11 新实验几乎全是单 seed。** E/F/A/方法搜索/EA-N2 都是 seed13；F7、E3、N2、S2 的排序会受初始化与 early-stop 噪声影响，不能替代三种子均值。
3. **协议漂移。** 旧主表 20 epoch 固定；P0 早期 30 epoch/patience7；第一轮 30 epoch/patience7；确认性 F 系列部分 50 epoch；方法搜索 40 epoch/patience8；SIMS 20 epoch 不早停。跨 campaign 的同名方法数值不可直接比较。
4. **MOSI 验证集很小。** 229 条（非零 216）；14 方法筛选、单 seed 调参和 First-order 的高方差都受此影响。validation 最优与 test 最优频繁不一致，说明选模本身是高方差环节。
5. **外部 KD 基线只有 seed13。** Projector/EA-KD/CMAD 和 Adapted Student 没有三种子；不能把它们与 ICD 的三种子均值做正式排名。EA-KD-Full 也只有单 seed 搜索。
6. **MOSEI Ensemble 只有 1/3 seed。** seeds 42/2026 在 epoch 7 暂停；Ensemble 的 `0.4869` 是单 seed，不能与三种子方法直接比较。
7. **标准差不是置信区间。** 三种子 `±` 是 sample SD；没有做多重比较校正；多数“均值更好”不能升级为“显著更好”。
8. **视频通道弱。** V 单模态教师 MAE `0.7198`/`1.4046`；16 帧全段采样、中心裁剪、VideoMAE 冻结/仅 LoRA，都是潜在瓶颈；本轮没有完成人脸/多 clip 主实验。
9. **教师不是上界。** 30B + Probe 的 test MAE `0.4429`/`0.4802` 也受标签噪声和 Probe 限制；学生差距不能全部归因于学生容量。
10. **SIMS v2 划分重叠。** 原视频在官方 split 间存在重叠，未重新划分；跨数据集结论需保留这一限制。
11. **未完成/暂停项。** MOSEI Ensemble seeds 42/2026（epoch 7）、RDID-v2 Amplitude×U（19）、research smoke、部分 polarity/video adaptation run 仍为 paused/partial；报告没有把它们当作完成结果。
12. **2 个任务仍在跑。** `N2_mosei`、`EA_N2_mosei` 在 2026-11-11 19:15 仍为 running；`N2_sims_v2` 已完成并纳入第 6.4 节，其余在跑任务不写入结论。
13. **MAE 不可跨数据集比较。** MOSEI/MOSI `[-3,3]`，SIMS `[-1,1]`；本报告中的跨数据集表格只比较方法内部排序，不比较绝对 MAE。
14. **单 seed 的 test 排名有选择偏差。** 方法搜索明确把 test 用于探索性排序；即使报告写着“test 未参与选模”，多轮查看 test 也会造成隐含选择。任何后续确认都应使用预先冻结的配置与多种子。
15. **MOSI First 的 `last` checkpoint 不是选模口径。** `normalized_icd` 的 `last` `0.6851` 是整批最低，但 `last` 未经过 validation 选择；主表应使用 `valid_mae` / `valid_acc2`。不能把 `last` 最优值与 validation-selected 结果混排。

### 11.5 数据源优先级

当同一方法在不同文档/目录出现不同数值时，按以下优先级取数：

1. `ICD/ICD.pdf` 与 `docs/paper/icd_experiment_summary.md` 的当前口径（2026-09-24 快照）。
2. `project/reports/all_experiments_dual_checkpoint_20261014/` 的双 checkpoint 重建（旧主表主数据源；明确区分 policy 与 campaign）。
3. `outputs/experiments/<experiment_id>/` 的原始 `report.json` / `predictions.jsonl` / `run_config.json`。
4. `project/reports/*.json` 的专项统计（Stage A–D、fidelity、efficiency、teacher test）。
5. 2026-11 新 campaign 的 `summary.md` / `summary.json` / `analysis/*`；只在该 campaign 协议内比较。
6. `docs/archive/` 的历史快照；只用于追溯，不作为当前结论。

不要做的事：

- 不把 `test-best` 数值混入 `valid_mae` 表。
- 不把不同 campaign 的同名方法直接合并（例如 `uniform_main_v1`、`multiseed_controls_v1`、`icd_improvement_mosi_20261107`、`icd_confirmatory_mosi_v1` 中的 ICD）。
- 不把不同标度（`[-3,3]` vs `[-1,1]`）的 MAE 直接比较。
- 不用单一 seed 的最优值替代三种子均值。
- 不把 `±` 当作置信区间或显著性。
- 不把“test 用于探索性排序”的结果写成“确认性提升”。
