## 1. 最终研究问题

后续只回答五个问题：

1. Full KD 是否稳定优于 Student-only？
2. 受限的学生适配是否能释放教师知识，而不是依赖全参数解冻？
3. Reliability × Utility 是否在严格可比的适配学生上提供独立增益？
4. 视频信号是否被学生有效使用，轻量视觉适配能否改善 TAV？
5. 所有收益能否在三 seed、聚类统计、第二数据集和一次性 official test 上成立？

论文核心表述限定为：

> 交互结构重建更准确不必然改善任务；选择性蒸馏只有在学生表示具有足够可塑性、
> 且输入与监督严格对齐时，才可能转化为稳定下游收益。

Möbius/interaction 坐标是可逆重参数化，不宣称增加信息。创新来源必须是可靠性、
任务效用选择、学生适配或经验证的视频利用机制。

- 已完成的 legacy-v1 结果不重算、不改名，后续严格对照采用修正后的 v2 教师协议。

### 2.3 学生与基础输入

- 学生骨干：Qwen3-0.6B + WavLM + VideoMAE；
- F/C/P 既有实验使用已冻结的全量特征缓存；
- C Track 的 LoRA 仅作用于 Text 与 Audio attention projection；
- V Track 独立比较 frozen video、VideoMAE LoRA 与 TA-only；
- 所有同一对照矩阵必须使用相同输入路径、初始化、batch 顺序、训练预算、
  early-stop 和 checkpoint 选择规则；
- 不得把 cached-audio 基线与 online-audio LoRA 结果直接解释为纯 LoRA 因果效应。

### 2.4 主指标与模型选择

- 主指标：utterance-level MAE，越低越好；
- 次指标：Pearson、Acc-2、F1、Acc-7；
- valid 是唯一开发集；主模型按 valid MAE 选择；
- 每个正式配置固定 seeds 13、42、2026；
- 两 seed 只可用于筛选，三 seed 才能形成主结论；
- paired bootstrap 使用至少 10,000 次重采样，并按原始 video ID 聚类；
- 分类结论同时报告 McNemar 或等价的 paired test；
- 均值、标准差、逐 seed 胜负、95% CI 和效果量必须同时保留。

| B0 Student-only | 13/42/2026 | 0.5323±0.0080 | 0.7180±0.0073 | 0.8479±0.0082 | 0.8428±0.0107 | 0.5396±0.0062 | 基线 |
| B1 Full KD | 13/42/2026 | 0.5072±0.0046 | 0.7423±0.0064 | 0.8530±0.0060 | 0.8529±0.0049 | 0.5507±0.0043 | 稳定优于 B0 |

| Frozen RU | 13/42/2026 | 0.5055±0.0023 | — | — | — | — | 改善弱，CI 跨 0，未达 0.005 Gate |

拟合或部分次指标，但没有形成稳定任务收益，不能宣称优于 Full KD。

## 6. 核心归因矩阵 C-v2

目标是把“适配收益”和“选择性蒸馏收益”拆开。以下实验共享同一 online T/A 输入
路径、同一 frozen video 输入、相同初始化与训练预算：

| 编号 | 学生适配 | 蒸馏监督 | 回答的问题 |
|---|---|---|---|
| C-1 | 无 LoRA，online-path control | Full KD | online 与 cached 输入差异 |
| C0 | LoRA(T+A) | 无 KD，仅任务标签 | LoRA 本身带来的收益 |
| C1 | LoRA(T+A) | Full KD | 通用教师监督的增益 |
| C2 | LoRA(T+A) | uniform ensemble-pair | 多教师/交互监督但无 RU 权重的增益 |
| C3 | LoRA(T+A) | Reliability × Utility pair | RU 权重的独立增益 |

执行规则：

1. 先在 seeds 13、42 跑完整矩阵，不允许只补有利单元；
2. 所有方法从相同 seed 的基座与 head 初始化开始；
3. 若某方法相对直接前序对照 MAE 改善至少 0.005，且 2/2 seeds 同向，补 seed2026；
4. C3 必须分别对 C1、C2 做聚类 paired bootstrap；
5. 若 C3 仅胜 C1 而不胜 C2，只能归因为 ensemble-pair 监督，不能归因为 RU；
6. 最终主方法优先按三 seed MAE，其次看 CI、Pearson 与分类指标一致性。

当前 D1/D2 已完成并应冻结，作为 v1 强信号和实现检查；C-v2 才是论文最终消融。
正式 video-cluster bootstrap 中，D1 相对 B1 的 MAE CI 在 3/3 seeds 不跨 0；
D2 相对 D1 只有 seed42 的 CI 不跨 0。因此 D2 可称为方向稳定的当前最优结果，
不能写成 3/3 seeds 均显著。

## 7. 视频 Track V

### 7.1 已有证据

- 教师 valid subset MAE：T 0.4813、A 0.4607、V 0.7257、TA 0.4562、
  TV 0.4605、AV 0.4444、TAV 0.4378；教师 TA→TAV 改善约 0.0184；
- 学生 B2 TA→TAV 平均只改善约 0.00346，逐 seed 聚类 CI 跨 0；
- 当前每个窗口均匀采 16 帧并 center crop；约 39.6% 窗口长于 7.5 秒，7.53%
  长于 15 秒，存在长视频欠采样与人物裁切风险；
- 未发现普遍黑帧或重复帧问题，因此首要假设是视觉采样/适配能力不足。

### 7.2 执行顺序

1. V3-v1：完成当前 frozen_video / video_lora / ta_only 控制实验；
2. V0：冻结模型上做 frame shuffle、temporal reverse、black/mean frame、video swap；
3. V1：人脸或上半身感兴趣区域裁切，对 center crop；
4. V2：多短 clip temporal pooling，对单个 16-frame uniform clip；
5. V3-v2：只在 V1/V2 显示有效后，以修正协议复验轻量 VideoMAE LoRA；
6. V4：质量门控，低质量视频退化为 TA，不让视觉噪声强制进入融合。

每一步都保留 TA-only、frozen-video 与目标方法三组。视频模块进入主模型的条件：

- 相对 TA-only 与 frozen-video 均改善 MAE；
- 三 seed 平均改善至少 0.005；
- video-cluster bootstrap 95% CI 不跨 0；
- 扰动测试能显示模型确实依赖有意义的视频内容。

未通过时，论文结论应是“当前 VideoMAE 输入未被学生稳定利用”，主模型采用 TA，
而不是继续扩大视频调参空间。

## 8. Sample-wise Utility Track U

目标是验证“哪些样本受 interaction supervision 帮助”是否可由训练时可见信息预测。

1. 仅在 official train 做 5-fold、按 video ID 分组的 cross-fitting；
2. 每折用未见样本的 Full KD 与 pair-KD 误差差生成 OOF utility target；
3. utility 特征只能来自推理时可用的教师不确定性、模态一致性、交互幅值、
   输入质量与长度，禁止使用真实 label 派生特征；
4. 从 logistic regression 开始，必要时才使用小型两层 MLP；
5. official valid 只用于一次校准和最终选择，不参与 OOF 标签生成。

五折分组已冻结在 `project/configs/utility_crossfit_5fold_v1.json`：各折包含
3,279–3,280 个 train windows、449–450 个 train videos，valid/test 均未分配。
当前只完成折划分；OOF 模型尚未训练，不得把既有 in-sample utility 诊断冒充 OOF
结果。

Gate：

- AUROC < 0.55：停止 learned utility；
- 0.55–0.60：仅作诊断，不训练完整主模型；
- ≥ 0.60：允许进入 C2/C3 对照；
- ≥ 0.65 且跨 seed 稳定：可作为论文正结果。

若 learned utility 失败，C3 使用预注册的 deterministic RU 权重，不继续堆叠复杂
selector。

## 9. 鲁棒性 Track R

只在 C Track 最终候选冻结后执行，不为每个中间方法重复跑：

- 缺失模态：drop T、A、V，以及可解释的组合；
- 音频噪声：预注册 SNR 档位；
- 视频退化：帧丢弃、模糊/遮挡、时间错位；
- 文本退化：mask 或 ASR 风格扰动；
- 同时报告绝对指标、相对 clean degradation 与 uncertainty/reliability 响应。

核心对照仅包含 Student-only、Full KD 与最终方法。鲁棒性不能与正常训练并发抢占
GPU 或改变主实验的数据顺序。

### 10.3 official test 一次性协议

满足以下全部条件后才解封：

1. 主方法、基线、超参、seeds、checkpoint 选择规则全部冻结；
2. CMU-MOSEI valid 的三 seed 表与聚类统计完成；
3. 代码、manifest、cache、config、checkpoint 均有 hash；
4. 论文主张与预注册 Gate 已确定；
5. 生成 `FINAL_TEST_UNLOCK.md`，记录时间、commit 和候选 checkpoint。

解封后只运行 Student-only、Full KD、最终方法各一次预注册评估；不根据 test 返回继续
选模型或调参。

## 11. 统一 Gate 与停止规则

| Gate | 通过条件 | 未通过处理 |
|---|---|---|
| 性能 Gate | 三 seed MAE 平均改善 ≥0.005，至少 2/3 seed 同向 | 不进入主线 |
| 显著性 Gate | video-cluster paired bootstrap 95% CI 不跨 0 | 降级为趋势/负结果 |
| 分类 Gate | Acc-2/F1 改善有 paired evidence，且 MAE 不明显恶化 | 否则不作分类主张 |
| RU 归因 Gate | C3 同时优于 C1 和 C2 | 否则限制归因 |
| 视频 Gate | 同时优于 TA-only 与 frozen-video，并通过扰动诊断 | 主模型使用 TA |
| Utility Gate | OOF AUROC ≥0.60 | 停止 learned selector |
| 跨数据集 Gate | MOSI 方向一致且无严重负迁移 | 仅声称 MOSEI 内有效 |

任何失败 Gate 都是正式结果。禁止在 valid 上无限追加 seed、权重、温度或结构直到
显著。

## 12. 实际执行优先级与 GPU 调度

### P0：不中断当前队列

1. D2 seed2026 已完成；
2. 完成正在运行的 Video v1 seed13，按 Gate 决定是否补两个 seeds；
3. D1/D2 聚类统计已完成；继续汇总 Video v1 的正式 `report.json`、预测和统计；
4. 冻结 legacy-v1 产物与 commit/tag。

### P1：实现审计与 C-v2

1. 完成第 5 节所有修正及单元/集成测试；
2. 构建同路径 C-1/C0/C1/C2/C3；
3. 两 seed 筛选，按预注册规则补第三 seed；
4. 确定论文主模型。

### P2：视频与 utility

- GPU 空闲时 V0 诊断可与 CPU 侧汇总并行；
- V1/V2/V3-v2 不与其他显存敏感训练并行；
- U 的特征表与 OOF 分折可在 CPU 侧准备，训练严格按 fold 运行。

### P3：收敛实验

2. CMU-MOSI 迁移；
3. 独占 GPU 效率测试；
4. 冻结论文表格；
5. 一次性 official test。

调度原则：可以并行的只是不会改变随机性、吞吐或显存压力的独立任务。正式计时、
显存、在线编码训练和同组对照尽量串行；若必须并行，整组对照需保持相同资源条件并
记录并发进程。

## 13. 论文结果结构

主文只保留四张核心表：

1. Frozen baselines：B0/B1/B2/RU；
2. Adaptation attribution：C0/C1/C2/C3；
3. Video contribution：TA-only/frozen-video/video-adapted；
4. Final generalization：MOSEI valid/test、MOSI、robustness 与效率。

附录包含逐 seed、所有 Gate、失败分支、教师七子集、interaction mean/variance/SNR、
bootstrap/McNemar、实现与算力配置。D3 hidden KD、Polarity KD 和 frozen RU 的负结果
保留，避免选择性报告。

允许的当前结论：

- Full KD 明确优于 Student-only；
- LoRA(T+A) 显著提高学生的可塑性和当前 valid 性能；
- RU+LoRA 三 seed 均优于同 seed D1，平均 MAE 再改善约 0.0082，但严格同路径归因
  尚未完成；
- 教师拥有视频互补信息，但当前学生的视频利用仍弱；
- interaction fidelity 与下游性能并非单调对应。

暂不允许的结论：

- RU 已被严格证明是 LoRA 增益的唯一原因；
- 当前 VideoMAE 已带来稳定主任务收益；
- hidden/polarity KD 有效；
- 已在 official test 或跨数据集上泛化。
