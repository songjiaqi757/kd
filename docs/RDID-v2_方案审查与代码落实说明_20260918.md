## 1. 审查结论

原方案的主因果问题、实验顺序和停止条件合理：先诊断 R×U 是否过度集中，再以 Soft-RU
连续插值，随后拆解 R/U，只有 Soft-RU 有正向证据时才启用 sample-level gate。MOSI
official-test 被保留为方法冻结后的独立确认集，这一边界必须继续维持。

实现前需要明确以下边界：

1. `S=max(valid MAE,test MAE)` 仍然是在使用 MOSEI test 选择方法。它适合作为开发分数，不能
   消除多候选试验带来的 test optimism，也不能让 MOSEI test 恢复为独立确认结果。汇总文件因此
   固定写入 `mosei_is_blind_confirmation=false`。
2. seed13 单种子适合当前受控筛选，但不能单独支持“机制稳定”或“方差更低”的论文结论。当前实现
   严格拒绝其他 seed，以遵守方案约束；最终论文应把 MOSI 独立结果与所有候选的透明披露一起报告。
3. 当前运行中的 `tav_epoch_checkpoints_v1` 使用旧 wrapper；其逐 epoch 文件明确排除了 optimizer
   和 RNG，不能称为本方案要求的“完整可恢复 checkpoint”。它仍可用于轨迹分析，但不得通过
   RDID-v2 checkpoint 审计。为避免破坏正在运行任务的源码指纹，本次没有修改旧入口。
4. M4/M6 历史 seed13 可作为 α=0/1 的性能端点；若要比较逐 epoch 轨迹或中断恢复行为，则必须用
   新协议重跑，不能把旧的轻量 epoch snapshot 与新 checkpoint 混称为同一保存协议。
5. Gate 的分母使用 train 中每个 parent utterance 唯一计数后的高阶 interaction strength 中位数，
   不能按 window 重复计数。若中位数为零，代码会拒绝运行，而不是静默产生极端 gate。
6. `Amplitude × U` 在旧主表代码中已有等价的 `amplitude_interaction`，但 RDID-v2 使用独立名称
   `amplitude_u`，避免修改冻结的主表方法集合。

## 2. 新增实现

### 交互权重与 Gate

`project/src/rdid_mosei/rdid_v2.py` 实现：

- Uniform、Soft-RU α=0.25/0.50/0.75、原始 RU；
- R-only、U-only、Amplitude×U；
- Soft-RU + sample-level interaction-strength gate；
- 每个 batch 的 weight mean/std/min/max、entropy、effective coordinate count 和 gate 统计。

Soft-RU 先完全复现冻结 M6 的 reliability 归一化与 `[0.25,4.0]` clip，再计算 RU 的最终
mean-one 权重，最后执行 `(1-alpha)+alpha*Q`。因此 α=0/1 分别严格等于 Uniform/RU。

### 独立训练入口

`project/scripts/train_rdid_v2.py` 只允许 `seed=13`，只读取 train/valid，并原生保存：

```text
checkpoints/epoch_001.pt
checkpoints/epoch_002.pt
...
best.pt -> checkpoints/epoch_BBB.pt
last.pt -> checkpoints/epoch_LLL.pt
```

每个 epoch checkpoint 包含可训练模型状态、optimizer、epoch、global step、best/stale 状态、
完整 history、run/method config、Python/NumPy/Torch CPU/Torch CUDA/DataLoader RNG。当前协议没有
scheduler、GradScaler，因此对应字段显式为 `null`。只有 inventory 覆盖全部 history epoch 后，
run 才会写成 `complete`。

训练 history 记录任务损失、Full-KD regression/KL、interaction loss、权重统计、valid 全指标、
learning rate、epoch wall time 和 peak GPU memory。checkpoint 始终只按 valid MAE 选择。

### Phase-A 与 test teacher interaction

- `project/scripts/analyze_rdid_v2_diagnostics.py`：A1/A2/A3，以及可选 A4；
- `project/scripts/infer_rdid_v2_test_interactions.py`：把三个冻结 train/valid Probe 应用于 test
  七子集特征，复用 train-derived empty baseline，不在 test 上训练或校准；
- `project/src/rdid_mosei/rdid_v2_diagnostics.py`：entropy、Neff、R 分解、clip 比例、七坐标分布、
  U_train/U_valid/U_test Pearson/Spearman 的纯数值实现。

test 七子集大模型特征仍由现有 `extract_teacher_probe_features.py` 提取；新增 inference 脚本只负责
Probe 推理和三 Probe interaction 聚合，避免复制 30B 教师加载逻辑。

### Development evaluation 与汇总

- `project/scripts/evaluate_rdid_v2_development.py`：只加载 valid-best checkpoint；一次性运行 MOSEI
  test；输出 gap 和 `max(valid,test)`；显式要求允许 development test 的开关；
- `project/scripts/summarize_rdid_v2_development.py`：合并六个新候选与 M4/M6 seed13 端点，拒绝
  非 valid-only checkpoint policy；
- `project/configs/rdid_v2_mosei/experiments.json`：冻结六个首轮 run，Gate 默认 disabled。

## 3. 预备命令（本次未执行）

先做不需要 test teacher 的 A1-A3：

```bash
python project/scripts/analyze_rdid_v2_diagnostics.py
```

构建 test 七子集教师特征和 interaction target：

```bash
python project/scripts/extract_teacher_probe_features.py \
  --manifest dataset/cmu_mosei/manifests/official_test_windowed.jsonl \
  --output-dir outputs/experiments/rdid_v2_mosei/diagnostics/test_teacher_features \
  --subsets t a v ta tv av tav --video-timing-policy sampled_fps_v2

python project/scripts/infer_rdid_v2_test_interactions.py \
  --features outputs/experiments/rdid_v2_mosei/diagnostics/test_teacher_features \
  --output outputs/experiments/rdid_v2_mosei/diagnostics/test_teacher_interactions \
  --allow-mosei-test-development

python project/scripts/analyze_rdid_v2_diagnostics.py \
  --test-interaction-targets \
  outputs/experiments/rdid_v2_mosei/diagnostics/test_teacher_interactions/interaction_targets.jsonl
```

单个候选的命令模板：

```bash
python project/scripts/train_rdid_v2.py \
  --method soft_ru_a025 --seed 13 \
  --output outputs/experiments/rdid_v2_mosei/students/soft_ru_a025_seed13
```

```text

r_only
u_only

```

```bash

  --output outputs/experiments/rdid_v2_mosei/development_test/soft_ru_a025 \
  --allow-mosei-development-test
```
