# 1. 后续研究口径统一

## 1.1 最终研究目标

项目的最终目标不是研究：

> “加入 Video 是否优于只使用 Text + Audio？”

而是研究：

> **如何将大型三模态教师中的 Text–Audio–Video 联合知识，有效蒸馏到资源受限的三模态学生模型中。**

最终模型从定义上就是：

\[
S_{\mathrm{final}}
=
S_T + S_A + S_V + F_{\mathrm{TAV}}
\]

其中：

- \(S_T\)：Text student encoder；
- \(S_A\)：Audio student encoder；
- \(S_V\)：Video student encoder；
- \(F_{\mathrm{TAV}}\)：三模态融合模块。

因此，后续所有正式主实验均默认：

\[
\boxed{\text{Student = T + A + V}}
\]

不再把 Video 视为需要经过实验决定是否保留的可选模态。

---

# 2. 如何重新定位已有 T/A 实验

早期的 Text + Audio 实验不应被解释为最终系统设计，而应该正式定义为：

> **Controlled Bimodal Mechanism-Validation Setting**

即：

> **双模态受控机制验证阶段。**

它的作用是降低变量数量和实验成本，在进入完整 T/A/V 系统之前验证蒸馏机制本身。

已有 T/A 实验主要回答了以下问题：

1. Student-only 与 Full KD 是否存在稳定差距；
2. frozen student 是否限制教师知识吸收；
3. student representation adaptation 是否重要；
4. interaction-level supervision 是否值得研究；
5. Reliability / Utility weighting 是否存在潜力；
6. interaction reconstruction accuracy 与最终任务性能之间是否等价。

因此实验路线应被描述为：

```text
T/A mechanism study
        │
        ▼
验证 KD / interaction / adaptation 机制
        │
        ▼
T/A/V full multimodal system
        │
        ▼
完整三模态蒸馏
```

而不是：

```text
T/A
 ↓
加入 Video
 ↓
验证 Video 有没有用
```

---

# 3. 当前已有实验可以支持的结论

## 3.1 Frozen Student 阶段

已有三 seed 结果：

| Method | Valid MAE |
|---|---:|
| Student-only | 0.5323 ± 0.0080 |
| Full KD | 0.5072 ± 0.0046 |
| Full KD + subset supervision | 0.5084 ± 0.0050 |

因此已经可以较稳定地得到：

\[
\boxed{\text{Full KD > Student-only}}
\]

说明教师监督本身能够有效改善学生。

---

## 3.2 Student Adaptation 阶段

已有 LoRA 实验表明：

\[
\text{Frozen Full KD}
\approx 0.507
\]

而经过轻量 representation adaptation 后：

\[
\text{Full KD + LoRA}
\approx 0.466
\]

这说明：

\[
\boxed{
\text{Student Plasticity 是知识蒸馏效果的重要限制因素}
}
\]

单纯增加教师监督并不够。

学生必须具有足够的表示调整能力，才能真正吸收教师知识。

---

## 3.3 Interaction KD 阶段

已有实验还得到一个非常重要的现象：

> interaction reconstruction error 大幅下降，并不意味着 downstream sentiment MAE 同比例下降。

即：

\[
E_{\mathrm{interaction}}\downarrow
\]

并不能保证：

\[
E_{\mathrm{task}}\downarrow
\]

因此论文不能简单建立在：

> “学生更加准确地重建教师 interaction，因此性能更好”

这个逻辑上。

更合理的研究假设是：

\[
\boxed{
\text{教师知识是否值得迁移}
+
\text{学生是否有能力吸收}
}
\]

共同决定最终效果。

# 11. Interaction supervision 的定义

教师对七个 non-empty modality subsets 提供：

```text
T
A
V
TA
TV
AV
TAV
```

得到：

\[
f(T),f(A),f(V),
f(T,A),f(T,V),f(A,V),
f(T,A,V)
\]

然后通过 Möbius transform 得到 interaction coordinates：

\[
I_T,I_A,I_V,
I_{TA},I_{TV},I_{AV},
I_{TAV}
\]

需要在论文中明确：

> Möbius transform 只是对七个 subset predictions 的可逆重参数化。

即：

\[
\boxed{
\text{Möbius transformation does not introduce new information}
}
\]

它的价值在于：

> 把教师预测表示为 main effects 与 cross-modal interaction effects，方便选择性蒸馏。

---

# 12. M4：Uniform Interaction Distillation

对 interaction coordinates 统一加权：

\[
L_{\mathrm{int}}
=
\frac1K
\sum_k
\mathrm{SmoothL1}
(
I^S_k,
I^T_k
)
\]

目标：

> 判断 interaction supervision 本身是否有增益。

关键比较：

\[
\boxed{M4\;vs\;M3}
\]

---

# 13. M5：Reliability-weighted Distillation

如果教师多个 Probe / ensemble 对某 interaction 给出：

\[
\mu_k,\sigma_k
\]

定义可靠性：

\[
R_k
=
\frac{|\mu_k|}
{\sqrt{\sigma_k^2+\epsilon}}
\]

之后归一化 / clipping。

Loss：

\[
L_{\mathrm{int}}
=
\sum_k
R_k
\cdot
\ell(I^S_k,I^T_k)
\]

核心问题：

> 对教师置信度更高的 interaction 给予更大的蒸馏权重，是否优于 uniform transfer？

比较：

\[
M5\;vs\;M4
\]

---

# 14. M6：Reliability × Utility Distillation

这是最终核心候选。

权重：

\[
W_k
=
R_k
\cdot
U_k
\]

其中：

- \(R_k\)：教师 interaction reliability；
- \(U_k\)：该 interaction 对任务性能的 estimated utility。

归一化：

\[
\tilde W_k
=
\frac{W_k}
{\frac1K\sum_k W_k}
\]

Interaction loss：

\[
L_{\mathrm{RU}}
=
\sum_k
\tilde W_k
\cdot
\ell(I^S_k,I^T_k)
\]

最终：

\[
L
=
L_{\mathrm{task}}
+
\lambda_{\mathrm{full}}
L_{\mathrm{FullKD}}
+
\lambda_{\mathrm{RU}}
L_{\mathrm{RU}}
\]

# 17. Video 实验重新定位

Video 后续实验不再承担：

> “证明 Video 是否应该存在”

这个任务。

其作用改成：

\[
\boxed{
\text{Tri-modal behavior diagnosis}
}
\]

即研究：

> 完整 TAV student 如何利用视觉信息。

---

# 18. Video Analysis A：Cross-source Video Swap

对于样本：

\[
(T_i,A_i,V_i)
\]

替换为：

\[
(T_i,A_i,V_j)
\]

其中：

\[
i\neq j
\]

记录：

\[
\Delta MAE
=
MAE_{\mathrm{swap}}
-
MAE_{\mathrm{normal}}
\]

如果：

\[
\Delta MAE>0
\]

说明 student prediction 确实依赖 sample-matched visual content。

当前已有结果已经呈现稳定的：

\[
\Delta MAE>0
\]

因此可以作为：

> 模型没有完全忽略视觉输入

的证据。

---

# 19. Video Analysis B：Frame-order Shuffle

将：

```text
[v1,v2,...,v16]
```

替换为随机顺序：

```text
[v7,v2,v15,...]
```

目标：

> 分析模型是否真正依赖 temporal ordering / motion。

如果影响较小：

不能解释为：

> Video 无效。

只能解释为：

> 当前学生更加依赖静态视觉内容，而非严格时间顺序。

---

# 20. Video Analysis C：Repeat Mid-frame

用单帧：

\[
v_{mid}
\]

重复构成整个 clip：

\[
[v_{mid},...,v_{mid}]
\]

与正常视频比较。

目的：

区分：

```text
static appearance
vs
temporal dynamics
```

# 21. TA-only 如何处理

TA-only 可以保留。

但必须放在：

```text
Ablation / Modality Diagnosis
```

而不是：

```text
Main Model Selection
```

TA-only 回答的是：

> 当移除 visual stream 时，完整系统的行为发生什么变化？

不是：

> 是否应该删除 Video？

因此：

\[
TA\;vs\;TAV
\]

属于 modality ablation。

---

> Video usefulness test

# 34. 最终论文故事线

完整论文可以形成以下逻辑。

### Step 1

大型 Omni 模型具有强大的多模态表征能力，但难以直接部署到资源受限设备。

因此需要：

\[
\text{Large TAV Teacher}
\rightarrow
\text{Compact TAV Student}
\]

---

### Step 2

普通 output-level KD 可以提升学生。

但是提升有限。

---

### Step 3

进一步分析发现：

> 学生即使可以更准确地拟合教师 interaction，也不一定取得更好的下游性能。

即：

\[
\text{interaction fidelity}
\neq
\text{task utility}
\]

---

### Step 4

原因之一是学生表示空间受到 frozen backbone 的限制。

因此引入轻量：

\[
\text{representation adaptation}
\]

允许学生更有效地吸收教师知识。

---

### Step 5

即使学生具备足够 plasticity，也没有必要平均蒸馏所有教师 interaction。

不同 interaction 存在：

```text
不同 reliability
不同 downstream utility
```

因此使用：

\[
\boxed{
Reliability
\times
Utility
}
\]

执行 selective interaction distillation。

---

### Step 6

最终在完整：

\[
T+A+V
\]

学生上验证整个方法。

并通过：

```text
video swap
frame shuffle
repeat frame
modality ablation
```

分析最终学生如何利用三模态信息。

# 35. 推荐最终方法逻辑

最终方法可以抽象为：

\[
\boxed{
\text{Adaptive Selective Multimodal Distillation}
}
\]

包含三个层级。

### Level 1：Task Supervision

\[
L_{\mathrm{task}}
\]

保证学生学习 ground-truth sentiment。

### Level 2：Full Teacher Distillation

\[
L_{\mathrm{fullKD}}
\]

传递教师整体任务知识。

### Level 3：Selective Interaction Distillation

\[
L_{\mathrm{interaction}}
\]

仅重点迁移：

\[
\text{reliable}
+
\text{useful}
\]

的 cross-modal teacher interactions。

总目标：

\[
\boxed{
L
=
L_{\mathrm{task}}
+
\lambda_1L_{\mathrm{fullKD}}
+
\lambda_2
\sum_k
R_kU_k
L_{\mathrm{interaction},k}
}
\]

同时通过 LoRA 提供：

\[
\boxed{
\text{student representation plasticity}
}
\]

# 39. 最终一句话研究定位

整个项目建议最终统一为：

> **我们研究如何将大型三模态教师中的联合多模态知识蒸馏到紧凑的 Text–Audio–Video 学生模型中。通过前期 T/A 受控实验，我们发现更准确地重建教师跨模态交互并不必然带来更好的下游性能；有效蒸馏同时依赖学生表示的可适配性以及教师交互知识本身的可靠性与任务效用。基于这一发现，我们在完整 T/A/V 学生上采用轻量表示适配与 Reliability × Utility 驱动的选择性交互蒸馏。**
