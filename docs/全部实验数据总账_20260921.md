## 口径说明

- `report_valid_*` 是原训练报告记录的选定 checkpoint 指标；`last_valid_*` 是 history 的最后一轮。两者同时保留。
- `training_epochs.csv` 保存完整轨迹，能恢复任意 epoch 的结果，不需要从最佳轮反推。
- test 是否参与 checkpoint 选择以各来源的 `selection_policy`、`checkpoint_selection` 和 `test_use_policy` 为准；总账不替来源改写口径。
- 同一模型的重跑、失败启动、smoke 和正式结果可能同时存在；总账保留它们的真实路径，不自动去重。
